# 主要内容.md

> 后端技术实例核心内容速查。

## 1. Java 核心

- **基础语法**：数据类型、变量、方法、OOP（封装/继承/多态）
- **集合框架**：Collection → List/Set/Queue/Map；ArrayList、HashMap、ConcurrentHashMap
- **并发**：Thread、Executor、synchronized、AQS、JUC
- **JVM**：类加载、字节码、内存模型、GC（JVM/JDK/JRE）、JIT
- **Java 8+**：Lambda、Stream、Optional、CompletableFuture

## 2. Spring 生态

- **Spring Boot**：自动配置、起步依赖、Actuator
- **Spring Cloud Gateway**：路由、断言、过滤器
- **Spring MVC**：DispatcherServlet、HandlerMapping
- **Spring Data JPA**：Repository、EntityManager
- **MyBatis**：Mapper、动态 SQL

## 3. 数据库与缓存

- **PostgreSQL**：MVCC、JSON、数组、窗口函数
- **Redis**：String/Hash/List/Set/ZSet、Pub/Sub、Stream
- **SQL 优化**：B+ 树索引、EXPLAIN、慢查询
- **事务**：ACID、隔离级别、分布式事务

## 4. 网络

- **TCP/IP**：3 次握手、4 次挥手、流量控制、拥塞控制
- **HTTP/HTTPS**：1.1/2/3、TLS、证书
- **RESTful**：URL 设计、状态码、幂等
- **Gateway**：路由、限流、熔断

## 5. 系统编程

- **进程/线程**：创建、调度、同步
- **IO 多路复用**：select/poll/epoll
- **内存**：虚拟内存、页面置换
- **锁**：互斥锁、读写锁、信号量

## 6. 算法

- **基础**：排序、搜索、哈希
- **树**：二叉树、B+ 树、红黑树
- **图**：BFS/DFS、最短路径
- **动态规划**：背包、最长子序列
