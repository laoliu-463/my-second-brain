# 术语表.md

> 后端技术实例统一口径。

## 框架与库

| 术语 | 含义 |
|---|---|
| Spring Boot | Java 后端框架（V1 使用 3.2）|
| Spring Cloud Gateway | 路由 + 鉴权 + 限流 |
| Spring MVC | Web 框架 |
| JPA | ORM 规范 |
| MyBatis | SQL Mapper |
| Maven | 构建工具 |
| JUnit 5 | Java 单测框架 |

## 数据

| 术语 | 含义 |
|---|---|
| PostgreSQL | V1 关系数据库 |
| Redis | V1 缓存 |
| JDBC | Java DB 连接 |
| B+ 树 | 数据库索引结构 |
| MVCC | 多版本并发控制 |
| 索引 | 加速查询的数据结构 |

| 术语 | 含义 |
|---|---|

| 字节码 | JVM 执行的中间代码 |

## 协议与网络

| 术语 | 含义 |
|---|---|
| TCP/IP | 传输控制协议 |
