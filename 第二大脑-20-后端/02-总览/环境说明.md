# 环境说明.md

> 后端技术实例的运行环境说明。

## 1. V1 后端环境

| 环境 | 端口 | Compose | 后端 |
|---|---|---|---|
| test | 8080 | docker-compose.test.yml | backend |
| real-pre（本地）| 8081 | docker-compose.real-pre.yml | backend-real-pre |
| real-pre（远端）| 8081 | 1.14.108.159 | /opt/saas/app/ |

## 2. 后端构建

```bash
cd backend
mvn test
mvn spring-boot:run
mvn clean package
```

## 3. 必保开关

```text
APP_TEST_ENABLED=false        # real-pre 必须 false
DOUYIN_TEST_ENABLED=false     # real-pre 必须 false
DOUYIN_REAL_UPSTREAM_MODE=live
```

## 4. 健康检查

- 后端：`curl http://127.0.0.1:8081/api/system/health`（real-pre）
- 启动后等待 60-90 秒（Spring Boot 初始化）

## 5. 远端

- IP：1.14.108.159
- 目录：`/opt/saas/app/`
- 部署入口：`harness/scripts/commands/deploy-remote.ps1`
