# 已确认决策.md

> 后端技术实例的决策摘要。

## V1 后端技术栈

| 决策 | 主源 |
|---|---|
| Java 17 | ADR-001 模块化单体 |
| Spring Boot 3.2 | 业务主框架 |
| Spring Cloud Gateway | 路由 + 鉴权 + 限流 |
| PostgreSQL 13+ | 关系数据库 |
| Redis | 缓存 |
| Docker Compose | 部署（test / real-pre）|
| 模块化单体 | 不拆微服务 |

## V1 不做

- ❌ FastAPI / Celery / 爬虫（V2.2 设想）
- ❌ Kafka / RabbitMQ（V1 用 Spring 本地事件 + Outbox）
- ❌ 微服务拆分
- ❌ MySQL / MongoDB（统一 PostgreSQL）
- ❌ jQuery / Vue 2 / Element UI（统一 Vue 3 / Naive UI）
