# 分类、标题与目录决策表

## 文件分类

| 类型 | 判断依据 | 目标动作 |
|---|---|---|
| raw-source | 保存完整原始正文、PDF、网页快照或逐字稿 | 保持不可变，归档到来源目录 |
| source-note | 只围绕一个来源进行摘要、摘录和批注 | 建立或合并为唯一来源页 |
| concept | 可独立解释、复用和持续更新的概念或方法 | 合并同义页面并保留来源回链 |
| entity | 人、组织、产品、项目等稳定对象 | 使用正式名称，聚合跨来源事实 |
| synthesis | 跨来源比较、决策、时间线或结论 | 明示证据、推断与不确定性 |
| question | 尚无充分证据的问题 | 记录已知、未知和所需证据 |
| mixed | 原文、摘要、批注或多个概念混杂 | 原文保留；来源内容与知识内容分拆 |
| unknown | 信息不足或用途不明 | 保持原位并进入复核清单 |

## 三种名称

| 字段 | 用途 | 是否可改 |
|---|---|---|
| original_title | 作者原始标题 | 不规范化、不覆盖 |
| title | 人类阅读用显示标题 | 可适度规范化 |
| id / filename | 稳定机器标识 | 原则上不随标题变化 |

## 是否创建独立知识页

创建：

- 会被独立检索或多次复用
- 至少两个来源支持，或明确是领域标准概念
- 与多个页面形成稳定关系
- 对实践、解释或决策有长期价值

不创建：

- 只是一篇文章的修辞或章节标题
- 只出现一次且无复用价值
- 只是案例、故事或引用
- 证据不足或定义不清
- 与已有页面只是同义关系

## 目录决策

优先：

```text
按页面类型 → links/tags → maps/MOC
```

避免：

```text
按唯一主题 → 多层子主题 → 每篇文章一个目录
```
