# 验收清单

完成一个批次前逐项检查：

- [ ] 已读取现有规则和目录约定
- [ ] 已记录修改前 Git 状态或文件哈希清单
- [ ] 原文内容未被改写或覆盖
- [ ] 原文移动前后哈希一致
- [ ] 每份来源只有一个主来源页
- [ ] 作者原标题保存在 `original_title`
- [ ] 显示标题与稳定 ID/文件名已分离
- [ ] 同义概念通过 aliases 合并，而非重复建页
- [ ] 知识页按概念或实体组织，而非按文章组织
- [ ] 新增知识结论带有来源回链和证据位置
- [ ] 冲突观点均被保留并标明来源及日期
- [ ] 目录主要按页面类型组织
- [ ] 多主题关系通过链接、topics/tags 或 maps 表达
- [ ] 页面移动后无新增断链
- [ ] 未自动删除文件或提交 Git
- [ ] 已更新 inventory、migration plan、distillation log 和 unresolved items
- [ ] 第二次运行不会重复创建同一页面
- [ ] 最终报告包含 diff 摘要和人工复核项
