## 1. 必会主题

- 短链生成
- URL 缩短
- 微博 / Twitter（feed / timeline）
- 秒杀系统
- 限流 / 熔断
- 分布式锁
- 消息队列
- 分布式 ID
- 一致性哈希
- 分布式事务

## 2. 4S 分析法

- **Scenario**：场景（QPS / DAU）
- **Service**：服务（拆解 / 微服务）
- **Storage**：存储（DB / Cache / 消息）
- **Scale**：扩展（读写分离 / 分库分表）

## 3. 经典案例

- Twitter Timeline：推 / 拉结合
- 秒杀：限流 + 异步 + 缓存
- 短链：哈希 + 缓存 + 重定向
- Feed：拉（关注者少）/ 推（关注者多）/ 混合
