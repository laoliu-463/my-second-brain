## 1. 必备结构（STAR）

- **S**ituation：情境（背景 / 挑战）
- **T**ask：任务（你的目标）
- **A**ction：行动（你做了什么）
- **R**esult：结果（数据 + 反思）

## 2. 必讲

- 项目背景：业务 / 用户 / 规模
- 你的角色 + 责任
- 关键技术决策 + 原因
- 难点 + 解决
- 数据指标（QPS / DAU / 错误率）
- 反思 + 改进

## 3. 常见问题

- 你负责什么？
- 用了什么技术？为什么？
- 最大的挑战？
- 怎么衡量效果？
- 如果重做会改什么？

## 4. V1 项目亮点

- 抖音/抖店 API 集成
- 订单归因链路
- 业绩双轨计算
- Spring Cloud Gateway
- real-pre 部署
