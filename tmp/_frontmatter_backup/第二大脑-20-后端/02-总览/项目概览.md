# 项目概览.md

> 后端技术实例概览。

## 1. 主题

后端技术知识库：Java / JavaScript / Node.js / 系统编程 / 网络 / 数据库 / 算法 / 数学 / 计算机基础。

## 2. 核心子分类

| 子分类 | 主题 | V1 项目实际使用 |
|---|---|---|
| Java体系 | Java 语法 / 集合 / 并发 / JVM / Spring | ✓ Spring Boot 3.2 / Java 17 |
| JavaScript体系 | JS 基础 / ES6+ / CSS / Vue | ✓ Vue 3 / Vite / TS |
| Node.js体系 | 事件循环 / 模块 / Stream | ✓ 仓库根 npm scripts |
| 系统编程 | OS 理论 / Linux | ✓ Docker Compose |
| 网络与分布式 | TCP/IP / HTTP | ✓ Spring Cloud Gateway |
| 数据库与缓存 | Redis / PostgreSQL | ✓ PostgreSQL + Redis |
| 算法与数据结构 | 经典算法 | ✓ SQL 索引 |
| 数学基础 | 概率 / 离散 / 线性代数 | △ 决策思维 |
| 计算机基础 | JIT / 编译 / 计算机组成 | △ JVM 调优 |

## 3. V1 后端栈

| 层 | 选型 |
|---|---|
| 语言 | Java 17 |
| 框架 | Spring Boot 3.2 + Spring Cloud Gateway |
| ORM | JPA + MyBatis |
| DB | PostgreSQL 13+ |
| 缓存 | Redis |
| 部署 | Docker Compose（test / real-pre）|
| 构建 | Maven 3.9+ |
| 验证 | Maven 单测 + PowerShell QA 脚本 |

## 4. 关键边界

- V1 用 Spring Boot，**不用 FastAPI / Celery / 爬虫**
- V1 模块化单体，**不拆微服务**
- V1 不用 Kafka / RabbitMQ（Spring 本地事件 + Outbox）
