# 金融战.md

> 金融战（中美博弈中的金融维度）。

## 1. 核心论点

- 金融是国家间博弈的高级形态
- 美元霸权是美国的核心战略优势
- 中国通过人民币国际化、SWIFT 替代、双边本币结算应对

## 2. 关键武器

| 工具 | 使用方 | 影响 |
|---|---|---|
| SWIFT | 美国主导 | 切断金融连接 |
| CHIPS | 美联储 | 切断美元清算 |
| 美元结算 | 全球 | 汇率风险 |
| 制裁名单 | OFAC | 资产冻结 |
| 评级机构 | 美三大 | 国家信用 |
| IMF/世行 | 美主导 | 救助条件 |
| 汇率操纵指控 | 美财政部 | 关税报复 |

## 3. 关键事件

- 2012 朝鲜制裁
- 2014 俄罗斯克里米亚制裁
- 2015 伊朗 JCPOA 协议
- 2018 退出 JCPOA、恢复对伊朗制裁
- 2022 俄罗斯 SWIFT 制裁
- 2022 冻结俄罗斯央行外汇储备

## 4. 关键参与者

- 美联储（Fed）
- 美国财政部 OFAC
- SWIFT（比利时）
- 环球银行金融电信协会
- CIPS（人民币跨境支付系统）
- mBridge（多边央行数字货币桥）

## 5. 中国应对

- 数字人民币 eCNY
- CIPS 推广
- 本币结算（与沙特、巴西等）
- 香港人民币离岸中心
- 黄金储备增加
