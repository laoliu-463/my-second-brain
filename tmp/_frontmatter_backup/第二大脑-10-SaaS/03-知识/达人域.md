# 达人域.md

> V1 达人域业务合同。

## 领域职责

- 达人资料
- 标签
- 地址
- 跟进记录
- 认领 / 保护期
- 向寄样、商品、业绩提供达人事实

## 领域不负责

- 订单事实采集
- 业绩计算
- 提成计算

## V1 规则

| 规则 | 说明 |
|---|---|
| 资料来源 | 抖音接口 + 团长录入 |
| 认领 | 团长认领达人 |
| 保护期 | 防止重复认领 |
| 标签 | 分类管理 |
| 地址 | 寄样消费 |
