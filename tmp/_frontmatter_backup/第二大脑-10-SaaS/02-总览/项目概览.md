# 项目概览.md

> 抖音团长 SaaS V1 项目背景。

## 1. 项目名

**colonel-saas**（抖音团长 SaaS 系统 V1）。面向抖音/抖店生态的团长业务管理平台。

## 2. 三条主链

- 渠道链：认领 → 选品 → 转链 → 寄样 → 业绩
- 招商链：商品库 → 招商 → 业绩
- 管理链：组织 → 权限 → 数据范围

## 3. 八个领域

- 用户域 / 配置域 / 商品域 / 达人域
- 寄样域 / 订单域 / 业绩域 / 分析模块

## 4. 技术栈

| 维度 | 选型 | 版本 |
|---|---|---|
| 后端 | Spring Boot / Java | 3.2.5 / 17 |
| 前端 | Vue / Vite / Pinia / TypeScript | 3.5.32 / 8.0.9 / 3.0.4 / 6.0.2 |
| ORM | MyBatis-Plus | 3.5.6 |
| 数据库 | PostgreSQL | 15 |
| 缓存 | Redis | 7 |
| 鉴权 | Spring Security + JWT | jjwt 0.12.5 |
| 测试 | JUnit 5 + Testcontainers | 1.19.8 |
| API文档 | Knife4j | 4.5.0 |

## 5. 部署

- test：本地 mock / seed
- real-pre：真实抖音接口联调（也是当前生产形态）
- 服务器：1.14.108.159（SSH别名 saas）
- 当前分支：feature/auth-system
- 测试状态：1499 tests, 0 failures
