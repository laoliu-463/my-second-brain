# 认知偏差.md

> 认知偏差清单。常见的思维陷阱。

## 1. 决策类

| 偏差 | 含义 |
|---|---|
| 锚定效应 | 决策被初始信息影响 |
| 损失厌恶 | 损失 1 单位的痛苦 > 获得 1 单位的快乐 |
| 沉没成本 | 投入越多越不肯放弃 |
| 过度自信 | 高估自己判断的准确性 |
| 确认偏误 | 倾向找支持自己观点的证据 |
| 锚定 + 调整 | 决策调整不够 |
| 现状偏好 | 倾向维持现状 |
| 反射效应 | 低概率高收益 → 低估；高概率低损失 → 高估 |
| 处置效应 | 急于卖出盈利，拖延卖出亏损 |
| 心理账户 | 钱有"标签" |

## 2. 信息处理

| 偏差 | 含义 |
|---|---|
| 可得性启发 | 容易想到的事 → 概率高估 |
| 代表性启发 | 用典型代表整体 |
| 锚定 | 第一印象过强 |
| 框架效应 | 同一问题不同框架 → 不同答案 |
| 叙事偏差 | 把随机事件讲成故事 |

## 3. 群体类

| 偏差 | 含义 |
|---|---|
| 从众效应 | 跟着大多数人 |
| 群体极化 | 群体讨论走向极端 |
| 信息级联 | 跟着前人决策 |
| 旁观者效应 | 责任分散 |

## 4. 自我类

| 偏差 | 含义 |
|---|---|
| 自利归因 | 成功归因自己，失败归因外部 |
| Dunning-Kruger | 能力差的人高估自己 |
| 虚假同感 | 高估他人与自己一致 |
| 后见之明 | 事后觉得早就知道 |

## 5. 时间类

| 偏差 | 含义 |
|---|---|
| 短期倾向 | 重视眼前、忽视长期 |
| 拖延 | 推迟该做的事 |
| 峰终定律 | 体验由最高峰 + 结尾决定 |

## 6. 缓解方法

1. **预设决策流程**：重要决策用 checklist
2. **寻求反向意见**：故意找反驳
3. **多视角**：换角色思考
4. **数据驱动**：用数字而非感觉
5. **慢决策**：重要决策不要 1 秒下
