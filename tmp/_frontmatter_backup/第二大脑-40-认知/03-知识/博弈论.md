# 博弈论.md

> 博弈论 / 多人决策。

## 1. 经典概念

- **参与者 / Players**：决策主体
- **策略 / Strategies**：可选行动
- **收益 / Payoffs**：各策略组合下的结果
- **均衡 / Equilibrium**：没人愿意单方面改变的状态

## 2. 均衡类型

### 2.1 纳什均衡

- 任何一方单独改变策略都不能获益
- 囚徒困境是典型
- 不一定是帕累托最优

### 2.2 帕累托最优

- 没人能变好而不让别人变差
- 比纳什均衡更"优"
- 但难达成

### 2.3 主导策略

- 不论对方选什么，自己选这个总是最好的
- 很少见，存在则决定胜负

## 3. 经典模型

### 3.1 囚徒困境

```
           对方合作      对方背叛
我合作    (-1,-1)      (-10, 0)
我背叛    (0, -10)     (-5, -5)
```

- 双方理性 → 双方背叛 → 集体次优
- 解决：重复博弈 / 信任 / 外部强制

### 3.2 智猪博弈

- 大猪 / 小猪 / 按键
- 大猪按，小猪等
- 类比：先动者 vs 后动者

### 3.3 斗鸡博弈

- 谁先让步谁输
- 关键：声誉 / 不可逆承诺

### 3.4 协调博弈

- 双方选相同策略得高分
- 例：左右行驶、操作系统

### 3.5 公共品博弈

- 所有人贡献 / 所有人获益
- 搭便车问题

## 4. 商业应用

- **价格战**：囚徒困境
- **平台双边**：协调博弈
- **专利与开源**：重复博弈
- **工会与雇主**：斗鸡
- **政府与企业**：智猪

## 5. V1 项目应用

- 业务决策：考虑多方利益（团长/达人/平台）
- 系统设计：接口兼容性 = 协调博弈
- 真实闭环：渠道归因需要上下游合作
