# 测试：Hermes Agent 发布验证

这是一篇**自动发布测试文章**，用于验证 md2wechat 工具链是否正常工作。

## 核心功能

md2wechat 支持以下核心功能：

- **Markdown 转微信格式**：一行命令完成排版
- **风格写作**：内置 Dan Koe 等多种写作风格
- **AI 去痕**：去除 AI 生成痕迹
- **草稿推送**：直接发送到微信草稿箱

## 使用方法

```bash
# 检查 metadata
md2wechat inspect article.md

# 预览效果
md2wechat preview article.md

# 发送到草稿箱
md2wechat convert article.md --draft --cover cover.jpg
```

## 结论

如果能看到这篇文章，说明发布流程一切正常。
