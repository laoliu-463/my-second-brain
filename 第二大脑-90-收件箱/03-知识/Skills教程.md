# Skills教程.md

> Skills / Agent 技能体系入门摘录。源：`00-收件箱/Skills 教程  菜鸟教程.md`。

## 1. 核心观点

- Skills 是把领域知识和行为封装成可复用指令集合，让 Agent 在上下文里“会做”而不只是“会说”。
- 学习链路是从通用能力向专业能力收敛：模型负责理解与规划，Skills 负责可执行动作。
- 对知识库而言，Skills 更适合作为行为标准化入口，而不是替代决策文档或业务规则文档。

## 2. 实操边界

- 不替代核心业务规则，不承载未经验证的事实判断。
- 不直接做“业务重写”，先定义动作边界与输入输出，再执行最小闭环验证。
- 与 `ask-matt` 的路由职责一致：先判断任务类型，再落地到固定流程。

## 3. 结构化提炼

- 能力定义（模型负责推理，Skill 负责执行）。
- 输入输出标准化（参数、返回码、错误处理）。
- 可追溯性（日志、模板、验收门槛）。
