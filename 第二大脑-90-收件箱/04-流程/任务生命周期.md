# 任务生命周期.md

> 本实例任务从 NEW 到 DONE。

## 1. 状态机

```
NEW → WIP → REVIEW → DONE
       ↓
     BLOCKED → WIP → REVIEW → DONE
```

## 2. 写任务

填 `05-任务/任务-XXX.md` 模板：

```text
# 任务标题
> 1-2 句描述
## 任务 ID
## 状态
## 触发
## 步骤
## 证据
## 关联
```

## 3. 完成

- 更新 `01-状态/当前状态.md`
- 追加 `日志.md`
- 写 `06-报告/报告-XXX.md`
