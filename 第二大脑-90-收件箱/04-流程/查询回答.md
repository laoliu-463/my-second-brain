# 查询回答流程.md

> 如何基于本实例回答问题。

## 1. 触发

- 用户说"查一下"
- Agent 在本实例覆盖范围

## 2. 步骤

### Step 1：定位入口

| 问题类型 | 入口 |
|---|---|
| 状态类 | `01-状态/当前状态.md` |
| 决策类 | `01-状态/已确认决策.md` |
| 业务类 | `02-总览/项目概览.md` |
| 领域类 | `03-知识/<领域>.md` |

### Step 2：读相关文件

- 不超过 3 个文件
- 80% 信息在前 50 行

### Step 3：回答 + 引用

- 直接回答
- 给 wiki link 跳转
