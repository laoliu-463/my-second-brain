# 系统思维.md

> 系统思维 / 复杂系统。

## 1. 系统 vs 堆叠

- **堆叠**：把部件拼起来
- **系统**：部件之间有反馈、有涌现

## 2. 关键概念

### 2.1 反馈回路

- **正反馈**：A→B→A（增长螺旋）
- **负反馈**：A→B→-A（稳定器）

### 2.2 涌现

- 整体 > 部分之和
- 例：交通堵塞 = 司机独立决策的涌现

### 2.3 杠杆点

Donella Meadows 12 杠杆点（从低到高）：

1. 常数 / 参数
2. 缓冲器大小
3. 存量-流量结构
4. 延迟
5. 反馈回路
6. 信息流
7. 系统规则
8. 自组织能力
9. 目标
10. 范式
11. 超越范式

### 2.4 限制因素

- 短板效应（木桶原理）
- 找出"最弱"环节
- 投入资源解决

## 3. 思考工具

- **因果回路图**（CLD）
- **存量流量图**（SFD）
- **系统基模**：成长上限 / 共同悲剧 / 舍本逐末 / 富者愈富
- **冰山模型**：事件 → 模式 → 结构 → 心智

## 4. 常见系统陷阱

| 陷阱 | 描述 |
|---|---|
| 边际思维 | 只看一步不看回路 |
| 政策抗拒 | 解决方案被系统反弹 |
| 目标侵蚀 | 慢慢调低目标 |
| 共同悲剧 | 公地悲剧 |
| 竞争升级 | 军备竞赛 |
| 富者愈富 | 马太效应 |
| 舍本逐末 | 用短期治标 |
| 成长上限 | 限制因素出现 |

## 5. 应用

- **商业**：理解用户增长 / 飞轮
- **技术**：理解架构反馈 / 性能瓶颈
- **个人**：理解习惯 / 时间管理
- **社会**：理解舆论 / 经济周期

## 6. V1 项目

- 订单归因系统：订单→归因→业绩→统计
- 反馈回路：业绩不好→优化归因→业绩变好
- 限制因素：上游接口稳定性
