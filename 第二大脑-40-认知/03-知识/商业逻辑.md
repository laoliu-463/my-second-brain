# 商业逻辑.md

> 商业底层逻辑。

## 1. 商业本质

**商业是用产品/服务换取价值**。

- 用户付出金钱 / 时间 / 注意力
- 企业提供产品 / 服务 / 体验
- 双方都觉得"值"

## 2. 核心元素

| 元素 | 含义 |
|---|---|
| 用户 | 谁来付钱？|
| 痛点 | 用户的问题 / 欲望 |
| 价值主张 | 我们怎么解决 |
| 渠道 | 怎么触达用户 |
| 收入 | 怎么收钱 |
| 成本 | 怎么花钱 |
| 利润 | 收入 - 成本 |
| 护城河 | 别人进不来的壁垒 |

## 3. 商业模型

### 3.1 B2C（企业对消费者）

- 例：淘宝、美团、抖音
- 核心：流量 + 转化
- 关键：用户体验 / 复购

### 3.2 B2B（企业对企业）

- 例：阿里云、SaaS、咨询
- 核心：销售 + 客户成功
- 关键：ROI / 客户生命周期

### 3.3 C2C（消费者对消费者）

- 例：闲鱼、淘宝早期
- 核心：双边网络效应
- 关键：信任机制

### 3.4 P2P（点对点）

- 例：P2P 借贷
- 风险高，监管严

### 3.5 平台型

- 例：滴滴、Airbnb、抖音
- 核心：双边匹配
- 关键：供给 + 需求 + 定价

## 4. 收入模式

| 模式 | 例 |
|---|---|
| 销售 | 卖产品 |
| 订阅 | SaaS、会员 |
| 抽佣 | 平台 |
| 广告 | 流量 |
| 增值 | 游戏道具 |
| 数据 | 数据 API |
| 许可 | 版权 |

## 5. 飞轮模型

```text
好产品 → 口碑 → 更多用户 → 规模效应 → 成本下降 → 好产品
                                                  ↑
                                                  └─────┘
```

## 6. 关键指标

- LTV（客户生命周期价值）
- CAC（获客成本）
- LTV/CAC > 3 才健康
- MRR / ARR（月/年经常性收入）
- Churn（流失率）
- NRR（净收入留存）

## 7. V1 项目商业模式

- **B2B SaaS**（团长企业用户）
- 订阅制
- 核心价值：业绩归因 + 订单同步 + 提效
- 收入：订阅费 / 增值服务
- 成本：研发 / 销售 / 服务器
