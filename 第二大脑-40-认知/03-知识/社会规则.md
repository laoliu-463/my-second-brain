# 社会规则.md

> 社会规则 / 潜规则 / 显规则。

## 1. 显规则 vs 潜规则

| 维度 | 显规则 | 潜规则 |
|---|---|---|
| 载体 | 法律 / 规章 | 习俗 / 默认 |
| 可见性 | 公开 | 隐藏 |
| 强制力 | 国家机器 | 社会排斥 |
| 弹性 | 严格 | 灵活 |

## 2. 关键洞见

- **利益驱动**：多数人按利益而非规则行动
- **信息不对称**：掌握信息者占优
- **信任稀缺**：信任是社会资本
- **声誉机制**：长期博弈靠声誉
- **圈子文化**：资源在圈子里流转
- **权力关系**：权力分配决定规则

## 3. 商业 / 职场

- 显规则：KPI、规章、流程
- 潜规则：
  - 站队
  - 关键人脉
  - 信息源
  - 利益交换
  - 不在台面的"默契"
- 应对：观察 + 学习 + 适配

## 4. 中国 / 美国差异

| 维度 | 中国 | 美国 |
|---|---|---|
| 信任 | 圈子内高 | 制度信任高 |
| 规则 | 灵活 / 关系导向 | 严格 / 程序导向 |
| 商业 | 关系 + 战略 | 规则 + 战略 |
| 创新 | 政策驱动 | 市场驱动 |

## 5. V1 项目

- 抖音/抖店平台规则 → 显规则
- 团长 SaaS 实际运营 → 潜规则（达人关系、商品话术等）
- 系统设计：留 API 扩展点
