# 认知层级.md

> 认知层级 / 思维层级。

## 1. Bloom 分类学（认知领域）

| 层级 | 描述 | 动作 |
|---|---|---|
| 记忆 | 记住事实 | 复述、列举 |
| 理解 | 解释意思 | 总结、分类 |
| 应用 | 用到新场景 | 解决问题 |
| 分析 | 拆解结构 | 对比、归因 |
| 评价 | 做出判断 | 批判、选择 |
| 创造 | 组合新事物 | 设计、创新 |

## 2. DIKW 金字塔

```text
        Wisdom 智慧（知道为什么）
       /      \
     Information 信息（知道是什么）
    /          \
   Data         数据（原始观察）
```

- Data：原始事实
- Information：有结构的数据
- Knowledge：可应用的信息
- Wisdom：判断 + 远见

## 3. 思维层级

### 3.1 第一层：事件

- "今天 XX 发生了"
- 短视、被反应

### 3.2 第二层：模式

- "XX 经常发生"
- 中视、可预测

### 3.3 第三层：结构

- "XX 为什么会发生"
- 长视、可设计

### 3.4 第四层：心智

- "我们为什么关注 XX"
- 远视、可改变

## 4. 认知层级

- **L0 元认知**：知道自己在想什么
- **L1 反思**：能跳出自己
- **L2 系统**：能看到整体
- **L3 范式**：能挑战假设
- **L4 觉醒**：能跳出框架

## 5. 升级方法

1. 多角度：换角色看问题
2. 多尺度：放大缩小时间
3. 反事实：假设反面
4. 元认知：监控自己
5. 教学：讲给别人
