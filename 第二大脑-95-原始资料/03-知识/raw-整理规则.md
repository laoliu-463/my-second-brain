# raw-整理规则.md

> raw 资料整理规则。

## 1. 原则

- 第二大脑不复制原文
- 只放提炼 + 路径索引
- 源文件保留 vault 原位

## 2. 步骤

1. 识别主题（哪个第二大脑实例？）
2. 提炼关键内容，保持可读
3. 写进对应实例的 03-知识/
4. 源位置登记到 01-状态/资料来源.md

## 3. 异常

- 超过 200 行的源 → 保留 vault 原位
- PDF 扫描版 → 标占位 + 链接 PDF
- 重复内容 → 合并或选最新
