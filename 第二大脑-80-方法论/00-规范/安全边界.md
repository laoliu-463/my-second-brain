# 安全边界.md

> 本实例 Agent 禁止操作范围。

## 1. 绝对禁止

- 写业务代码
- 改 SQL migration
- 重启容器
- 远端部署
- git push
- 数据库写

## 2. 允许

- 读 vault + 项目源码
- 写本实例文件
- 改本实例索引
- 调 line_check.py / lint.py

## 3. 边界外操作

- 需要明确用户授权
- 写入 `01-状态/已确认决策.md`
