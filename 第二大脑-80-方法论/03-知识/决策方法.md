# 决策方法.md

> 决策方法（与 [[../第二大脑-40-认知/03-知识/决策框架]] 配合）。

## 1. 决策类型

| 类型 | 特点 | 方法 |
|---|---|---|
| 程序化 | 重复、有规则 | 流程 / checklist |
| 适应性 | 创新、不确定 | 假设 + 验证 |
| 战略 | 长期、影响大 | 多视角 + 推演 |
| 危机 | 时间紧、信息少 | 简化模型 + 行动 |

## 2. 决策陷阱

- 沉没成本
- 锚定
- 过度自信
- 群体盲从
- 信息过载
- 完美主义

## 3. 决策原则

- **数据优先**：数字比感觉准
- **多视角**：不只自己
- **写下来**：避免反复
- **设时限**：避免拖延
- **预设规则**：临场不慌
