# 学习方法.md

> 学习方法论。源：`知识库/04-方法论与工具/学习方法/` 4 md。

## 1. 学习金字塔

- 听课：5% 留存
- 阅读：10%
- 视听：20%
- 演示：30%
- 讨论：50%
- 实践：75%
- 教别人：90%

## 2. 主动学习

- **SQ3R**：Survey / Question / Read / Recite / Review
- **费曼技巧**：讲给小白听
- **番茄工作法**：25 min 专注 + 5 min 休息
- **刻意练习**：走出舒适区 + 反馈

## 3. 知识管理

- 输入：阅读 / 课程 / 实战
- 处理：笔记 / 思维导图
- 输出：写作 / 讲解 / 复用
- 复习：间隔重复 / Anki
