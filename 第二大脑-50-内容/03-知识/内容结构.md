# 内容结构.md

> 内容结构方法论。

## 1. 经典结构

### 1.1 总分总

```text
总：核心观点
分：3-5 个分论点 + 案例
总：总结 + 行动建议
```

### 1.2 SCQA

- **S**ituation：情境
- **C**omplication：冲突
- **Q**uestion：问题
- **A**nswer：答案

### 1.3 AIDA

- **A**ttention：注意
- **I**nterest：兴趣
- **D**esire：欲望
- **A**ction：行动

### 1.4 PREP

- **P**oint：观点
- **R**eason：理由
- **E**xample：案例
- **P**oint：重申观点

## 2. 视频脚本

- **钩子（0-15s）**：抓住注意力
- **痛点（15-60s）**：建立共鸣
- **方案（60-180s）**：给出解决
- **行动（最后 30s）**：CTA

## 3. 图文文章

- **标题**：钩子
- **导语**：引出主题
- **正文**：3-7 个小节
- **结尾**：总结 + 互动

## 4. 长文 / 系列

- 第一篇：钩子 + 总览
- 中间篇：逐个深挖
- 最终篇：整合 + 行动

## 5. 节奏

- 段落 ≤ 5 行
- 关键句加粗
- 关键图穿插
- 间隔用列表
