# 商品域.md

> V1 商品域业务合同。

## 领域职责

- 商品库管理
- 活动商品同步
- 商品展示输入
- 转链
- pick_source_mapping 落库
- 为订单归因提供映射

## 领域不负责

- 业绩计算
- 提成计算
- 寄样表直接写

## V1 规则

| 规则 | 说明 |
|---|---|
| 商品库 | 本地表 |
| 活动商品 | 抖音同步 |
| 转链 | 抖音转链接口 |
| 映射 | pick_source → product_id |
| repair | 历史断链修复 |

## 关键字段

- product_id
- activity_id
- pick_source
- promotion_status
