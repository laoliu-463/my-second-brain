# 寄样域.md

> V1 寄样域业务合同。

## 领域职责

- 寄样申请
- 审核
- 发货
- 物流
- 签收
- 待交作业 / 交作业完成
- **基于订单已同步事件**判断交作业完成

## 领域不负责

- 订单事实采集
- 业绩计算
- 提成计算
- 物流 API 阻塞主流程

## V1 规则

| 规则 | 说明 |
|---|---|
| 状态机 | 申请→审核→发货→签收→完成 |
| 完成条件 | channel_id + talent_id + product_id + pay_time |
| 幂等 | 重复订单事件 |
| BLOCKED | 订单样本不足 |

## 关键字段

- sample_id
- talent_id
- product_id
- channel_id
- status
- completed_at
