# 订单域.md

> V1 订单域业务合同。

## 领域职责

- 抖音订单同步、订单事实保存、订单明细
- 退款 / 售后事实保存
- 同步日志
- 保存 raw_payload、双轨金额输入、pick_source
- 订单已同步事件

## 领域不负责

- 业绩计算
- 提成计算
- 寄样完成状态更新

## V1 规则

| 规则 | 说明 |
|---|---|
| 同步入口 | 抖音订单接口 |
| 同步字段 | pick_source、colonel_buyin_id |
| 同步幂等 | 订单 ID + 渠道 |
| 退款事实 | 独立表，不直接改订单 |
| 同步日志 | 失败 / 成功都记 |

## 禁止越界

- 不计算提成
- 不写 performance_records
- 不直接更新寄样完成

## 验证方式

- real-pre 真实上游响应或 BLOCKED 证据
- 单测 + 集成测试
