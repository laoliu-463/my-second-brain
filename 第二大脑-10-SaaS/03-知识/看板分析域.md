# 看板分析域.md

> V1 分析模块业务合同。

## 领域职责

- Dashboard
- 报表
- 趋势 / 排行
- 对账
- 导出
- 只读汇总展示

## 领域不负责

- 重算业绩归因
- 写订单 / 寄样 / 业绩事实

## V1 规则

| 规则 | 说明 |
|---|---|
| 数据源 | 汇总表 + 事实查询 |
| 数据范围 | 按用户域权限 |
| 导出 | CSV / Excel |
| 对账 | admin / group / self 差异 |

## 关键指标

- 渠道业绩
- 招商业绩
- 寄样完成率
- 订单同步成功率
- 业绩冲正率
