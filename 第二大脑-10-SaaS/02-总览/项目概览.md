# 项目概览.md

> 抖音团长 SaaS V1 项目背景。

## 1. 项目名

**抖音团长 SaaS**（V1）。面向抖音/抖店生态的团长业务管理平台。

## 2. 三条主链

- 渠道链：认领 → 选品 → 转链 → 寄样 → 业绩
- 招商链：商品库 → 招商 → 业绩
- 管理链：组织 → 权限 → 数据范围

## 3. 八个领域

- 订单 / 业绩 / 商品 / 达人 / 寄样
- 用户配置 / 看板分析 / 抖音上游

## 4. 技术栈

| 维度 | 选型 |
|---|---|
| 后端 | Spring Boot 3.2 / Java 17 |
| 前端 | Vue 3 / Vite / Pinia |
| 数据库 | PostgreSQL 13+ |
| 缓存 | Redis |
| 鉴权 | Spring Security + JWT |

## 5. 部署

- test / real-pre（本地+远端）
- production：默认不操作
