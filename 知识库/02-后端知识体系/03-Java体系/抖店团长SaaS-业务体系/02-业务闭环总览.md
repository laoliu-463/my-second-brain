# 业务闭环总览

## 概述

核心价值：**流量分发有闭环，业绩归因有回流**。

商品通过转链形成可推广商品，达人通过寄样建立合作关系，订单通过 `pick_source` 回流后由业绩域计算最终归属，形成完整的业务闭环。

## 总体闭环

```
商品域：活动商品 → 转链 → pick_source_mapping
                ↓
达人域：达人资料 → 标签 → 地址 → 渠道关系
                ↓
寄样域：申请 → 审批 → 发货 → 订单已同步事件 → 交作业完成
                ↓
订单域：同步 → 订单事实 → 退款事实 → 发布事件
                ↓
业绩域：订单事实 + 映射 + 配置 → 最终归属 → 提成 → 冲正 → 汇总
                ↓
分析模块：只读汇总 → Dashboard / 报表 / 导出
```
