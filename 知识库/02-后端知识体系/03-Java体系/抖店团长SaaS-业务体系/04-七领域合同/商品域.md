# 商品域

## 领域定位

商品域负责商品库、活动商品、商品展示输入、转链和 `pick_source_mapping`，为订单归因提供映射事实，**不计算最终业绩和提成**。

## 职责边界

| 类型 | 内容 |
| --- | --- |
| 负责 | 商品库、活动商品同步、转链、`pick_source_mapping` 落库 |
| 不负责 | 订单最终归属、提成、冲正 |

## 关键事实

- 调用转链能力后必须落 `pick_source_mapping`
- `pick_source_mapping` 至少能支撑商品、达人/渠道、pick source、时间和第三方响应追溯

## 对外能力

| 能力 | 使用方 |
| --- | --- |
| 商品库查询 | 前端、招商、渠道 |
| 活动商品同步 | 招商、管理 |
| 转链 | 渠道、达人链路（落 pick_source_mapping） |
