# 达人域

## 领域定位

达人域负责达人资料、标签、地址、跟进和渠道关系，向寄样、商品和业绩链路提供达人事实，**不替代订单域或业绩域做最终归属**。

## 职责边界

| 类型 | 内容 |
| --- | --- |
| 负责 | 达人基础资料、标签、地址、跟进记录、渠道关系事实 |
| 不负责 | 订单事实采集、订单归属计算、提成、冲正 |

## 对外能力

| 能力 | 使用方 |
| --- | --- |
| 达人列表/详情 | 前端、寄样、招商 |
| 达人地址 | 寄样域（寄样发货） |
| 达人标签/跟进 | 渠道、招商、管理 |
