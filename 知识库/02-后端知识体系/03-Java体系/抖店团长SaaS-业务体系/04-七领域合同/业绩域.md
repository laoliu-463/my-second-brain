# 业绩域

## 领域定位

业绩域负责**最终归属、提成、冲正和双轨金额计算**。消费订单事实、商品映射、达人关系和配置参数，输出业绩明细与汇总。

## 职责边界

| 类型 | 内容 |
| --- | --- |
| 负责 | 最终归属、提成、冲正、双轨金额、独家覆盖规则执行 |
| 负责 | 汇总表刷新，供分析模块只读 |
| 不负责 | 抖店订单原始事实同步、商品转链 |

## 关键事实

- 业绩域是最终归属结论来源
- 必须保留输入来源（订单、商品映射、达人关系、配置版本），支持追溯

## 对外能力

| 能力 | 使用方 |
| --- | --- |
| 业绩计算 | 管理端、调度 |
| 冲正处理 | 管理端、分析模块 |
| 汇总刷新 | 分析模块（只读） |
