# 配置域

## 领域定位

配置域负责配置项、规则参数、配置变更日志和配置查询，**只提供配置事实，不执行具体业务规则**。

## 职责边界

| 类型 | 内容 |
| --- | --- |
| 负责 | 配置读取、保存、校验、审计 |
| 不负责 | 商品转链、订单归因、提成计算、寄样状态流转 |

## 对外能力

| 能力 | 使用方 |
| --- | --- |
| 配置读取 | 商品、订单、业绩、分析 |
| 规则参数查询 | 业绩域（读取配置执行规则） |
