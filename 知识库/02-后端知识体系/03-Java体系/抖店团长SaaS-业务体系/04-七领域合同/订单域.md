# 订单域

## 领域定位

订单域负责订单事实、订单明细、退款/售后事实和归因输入，**只存事实，不算提成，不应用独家覆盖**。

## 职责边界

| 类型 | 内容 |
| --- | --- |
| 负责 | 抖店订单同步、订单入库、退款事实、幂等、`pick_source` 等归因输入 |
| 负责 | 发布订单已同步、退款事实已同步事件 |
| 不负责 | 最终归属、提成、冲正、独家覆盖 |

## 关键事实

- 订单域是订单事实来源，不是业绩结论来源
- 退款事实必须独立保存，供业绩域处理冲正

## 对外能力

| 能力 | 使用方 |
| --- | --- |
| 订单同步 | 管理端、调度 |
| 订单事件发布 | 寄样域（判断交作业）、业绩域（计算归属） |
| 退款同步 | 业绩域（处理冲正） |
