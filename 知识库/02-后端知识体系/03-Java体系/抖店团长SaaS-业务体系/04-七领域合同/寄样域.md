# 寄样域

## 领域定位

寄样域负责寄样申请、审批、发货、物流、收货和交作业状态，**通过订单已同步事件判断交作业完成**。

## 职责边界

| 类型 | 内容 |
| --- | --- |
| 负责 | 寄样申请、审批、发货、状态机、交作业判断（基于订单已同步事件） |
| 不负责 | 订单事实同步、业绩归属、提成、冲正 |

## 关键事实

- 交作业完成判断必须以订单域发布的订单已同步事实为证据
- 寄样状态变更必须有操作者、时间、前后状态

## 对外能力

| 能力 | 使用方 |
| --- | --- |
| 寄样申请 | 渠道、招商 |
| 审批/发货 | 管理端、招商 |
| 交作业判断 | 消费订单已同步事件 |
