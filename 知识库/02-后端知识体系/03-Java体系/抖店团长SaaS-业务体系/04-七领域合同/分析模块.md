# 分析模块

## 领域定位

分析模块负责 Dashboard、报表、导出和只读汇总展示，**只读汇总表，不重算业绩归属**。

## 职责边界

| 类型 | 内容 |
| --- | --- |
| 负责 | Dashboard、报表、趋势、导出 |
| 负责 | 按用户数据范围读取汇总 |
| 不负责 | 订单同步、归因、提成、冲正 |

## 关键事实

- 分析模块消费业绩域和订单域已形成的汇总或事实查询
- **不得**通过重新扫描订单来产生新的最终归属

## 对外能力

| 能力 | 使用方 |
| --- | --- |
| Dashboard 汇总 | 管理端、渠道端 |
| 报表查询 | 管理端 |
| 导出 | 管理端 |
