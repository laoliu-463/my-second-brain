# 事件契约

## 概述

V1 采用 Spring 本地事件 + Outbox 记录，不强制引入 MQ。

## 核心事件

| 事件 | 生产者 | 消费者 | 关键载荷 |
| --- | --- | --- | --- |
| 用户数据范围已解析 | 用户域 | 各业务域查询侧 | `userId`、`role`、`scope` |
| 配置已变更 | 配置域 | 业绩域、商品域、审计 | `configKey`、`oldValue`、`newValue` |
| 商品已同步 | 商品域 | 商品库、分析模块 | `productId`、`activityId` |
| 商品转链已完成 | 商品域 | 订单域、业绩域 | `productId`、`pickSource`、`mappingId` |
| 寄样状态已变更 | 寄样域 | 分析模块、审计 | `sampleId`、`status` |
| 订单已同步 | 订单域 | 寄样域、业绩域、分析模块 | `orderId`、`pickSource`、`payAmount` |
| 退款事实已同步 | 订单域 | 业绩域、分析模块 | `refundId`、`orderId`、`refundAmount` |
| 业绩归属已计算 | 业绩域 | 分析模块、报表 | `orderId`、`ownerId`、`commissionAmount` |
| 业绩汇总已刷新 | 业绩域 | 分析模块 | `period`、`ownerId` |

## 明确不做

- 订单事件不携带最终提成结论
- 配置变更事件不直接触发业务动作
- 分析模块事件不反向修改订单或业绩事实
