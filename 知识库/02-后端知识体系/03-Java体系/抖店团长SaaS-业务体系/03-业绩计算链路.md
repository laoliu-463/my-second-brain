# 业绩计算链路

## 概述

基于订单事实、商品映射、达人关系和配置，计算最终归属、提成、冲正和双轨金额。输出业绩明细和汇总，供分析模块只读。

## 参与角色

业绩域、订单域、商品域、达人域、配置域、分析模块

## 主流程

1. 业绩域消费订单已同步事件或按任务扫描待计算订单事实
2. 业绩域读取商品映射、达人关系和配置版本
3. 业绩域执行最终归属和独家覆盖规则
4. 业绩域计算提成、毛利、双轨金额
5. 业绩域处理退款/售后事实产生冲正
6. 业绩域刷新汇总表
7. 分析模块读取汇总并展示
