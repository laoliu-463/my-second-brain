# 权限与数据范围

## 概述

用户域统一提供 `self/group/all` 数据范围，业务域不得自行发明数据范围语义。

## 数据范围定义

| 范围 | 含义 | 典型使用 |
| --- | --- | --- |
| `self` | 仅当前用户负责的数据 | 渠道个人商品、达人、订单、寄样 |
| `group` | 当前组织或团队范围 | 主管查看组内订单、业绩 |
| `all` | 管理员或授权全量范围 | 管理端看板、审计、配置 |

## 模块接入要求

| 模块 | 接入要求 | 风险 |
| --- | --- | --- |
| 商品域 | 列表、转链、映射按数据范围过滤 | 越权看到他人商品 |
| 达人域 | 资料、跟进、地址按角色和组织过滤 | 越权查看达人隐私 |
| 寄样域 | 申请、审批、发货权限分离 | 越权审批或修改状态 |
| 订单域 | 订单事实按数据范围过滤 | 越权查看订单 |
| 业绩域 | 业绩明细和汇总按数据范围过滤 | 越权查看提成 |
| 分析模块 | Dashboard 按当前用户范围读汇总 | 看板越权 |

## 技术实现

- `@RequireRoles` 注解：控制角色权限
- `@DataScope` 注解：控制数据范围过滤
- Spring Security Filter 链统一鉴权
- MyBatis-Plus 拦截器实现 `self/group/all` SQL 注入
