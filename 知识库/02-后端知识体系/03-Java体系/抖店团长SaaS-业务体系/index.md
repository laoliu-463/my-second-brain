# 抖店团长SaaS业务体系

## 概述

抖店团长SaaS的核心业务价值：**流量分发有闭环，业绩归因有回流**。

本系列从业务视角出发，按 **V1范围 → 主链路流程 → 七领域 → 工程支撑** 的顺序组织，忠实映射 `D:\Projects\SAAS\docs\` 中的主干文档，不混入代码实现细节。

## 系列结构

```
抖店团长SaaS-业务体系/
├── 01-V1交付范围与边界        # 必做/简化/不做/V2预留
├── 02-业务闭环总览            # 总体闭环 + 六条主链路入口

└── 06-架构决策（ADR）/        # 6个核心决策记录
```

## 核心业务闭环

```
商品：活动商品 → 转链 → pick_source_mapping
         ↓
达人：资料 → 标签 → 地址 → 渠道关系
         ↓
寄样：申请 → 审批 → 发货 → 订单已同步事件 → 交作业完成
         ↓
订单：同步 → 订单事实 → 退款事实 → 发布事件
         ↓
业绩：订单事实 + 映射 + 配置 → 最终归属 → 提成 → 冲正 → 汇总
         ↓
分析：只读汇总 → Dashboard / 报表 / 导出
```

## V1 核心原则

| 原则 | 说明 |
| --- | --- |
| 订单域只存事实 | 不算提成、不应用独家覆盖 |
| 业绩域负责归属 | 最终归属、提成、冲正由业绩域输出 |
| 分析模块只读 | 不重算业绩归属 |
| real-pre 不 mock | 必须有真实 Token、真实接口响应 |
| 当前代码优先 | 代码 > 当前 V1 文档 > 旧 V2.2 文档 |
