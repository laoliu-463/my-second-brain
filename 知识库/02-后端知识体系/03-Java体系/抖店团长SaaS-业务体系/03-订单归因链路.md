# 订单归因链路

## 概述

从商品转链到订单同步再到业绩归属形成可审计链路。订单域只存事实，业绩域输出最终归属。

## 参与角色

商品域、订单域、业绩域、配置域、达人域、用户域

## 主流程

1. 商品域调用转链接口并落 `pick_source_mapping`
2. 订单域同步订单事实，保存 `pick_source` 等归因输入
3. 订单域发布订单已同步事件
4. 业绩域读取订单事实、商品映射、达人关系和配置
5. 业绩域应用最终归属和独家覆盖规则
6. 业绩域写入业绩明细和汇总
7. 分析模块读取汇总展示，不重算归属

## 关键数据

`pick_source_mapping`、订单事实、退款事实、达人关系、配置版本、业绩明细、业绩汇总
