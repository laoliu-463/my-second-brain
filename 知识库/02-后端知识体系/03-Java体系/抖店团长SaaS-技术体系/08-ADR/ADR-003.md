# ADR-003 订单域只存事实

## 状态

**已采纳**

## 决策

- 订单域只保存订单事实、订单明细、退款/售后事实和归因输入
- 订单域发布订单已同步和退款事实已同步事件
- 订单域**不计算提成**、**不应用独家覆盖**、**不写最终业绩归属**

## 验证方式

- 抽取订单，检查订单表不包含最终提成结论
- 同一订单的业绩结论在业绩明细或汇总中找到
