# ADR-001 模块化单体

## 状态

**已采纳**

## 决策

- V1 采用模块化单体
- 领域通过包、服务、事件和数据边界隔离
- 事件以 Spring 本地事件和 Outbox 机制为主，不强制引入 MQ
- FastAPI/Celery/Python 不是当前架构事实

## 验证方式

- 检查 `backend/src/**`、`docker-compose.*.yml`、`.env.*` 和测试脚本
- 文档中 `FastAPI|Celery|fake-useragent` 仅允许出现在归档语境
