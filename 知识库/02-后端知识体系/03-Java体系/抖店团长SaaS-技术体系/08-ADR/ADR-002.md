# ADR-002 V1范围优先级

## 状态

**已采纳**，后续发现冲突继续追加

## 决策

- **当前事实优先级**：当前代码和可运行配置 > 当前 V1 文档 > 旧 V2.2 文档
- 发现冲突时，先记录冲突、证据和待确认问题，不自行猜测
- 旧 V2.2 中未进入 V1 的能力放入 `V2 预留` 或 `历史归档`

## 已发现冲突清单

| 冲突 | 当前处理 |
| --- | --- |
| 旧文档含 FastAPI/Celery/Python 爬虫 | 仅归档为历史背景 |
| 订单同步提及 Celery | 按 Spring Boot/Gateway/Job 口径 |
| 达人文档含 `Python+requests` | 通过系统内资料和 Gateway |
| 物流/达人接口缺权限包 | BLOCKED 必须保留真实证据 |
