# ADR-004 业绩域负责最终归属

## 状态

**已采纳**

## 决策

- 业绩域负责最终归属、提成、冲正和双轨金额计算
- 配置域提供规则参数，业绩域执行规则
- 业绩明细和汇总是最终业绩结论来源
- **任何其他领域不得写最终提成结论**

## 验证方式

- 单笔订单从订单事实、商品映射追溯到业绩明细
- 单笔退款从退款事实追溯到冲正记录
