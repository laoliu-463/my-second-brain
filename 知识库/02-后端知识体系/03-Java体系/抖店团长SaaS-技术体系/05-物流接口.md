# 物流接口

## 概述

支撑寄样发货、物流单号记录和必要的物流查询。真实接口不可用时，必须记录 BLOCKED 证据。

## 数据流

1. 寄样审批通过后进入发货
2. 管理端录入或接口获取物流单号
3. 如有接口权限，Gateway 调用物流接口查询状态
4. 寄样域记录物流事实和状态变更
