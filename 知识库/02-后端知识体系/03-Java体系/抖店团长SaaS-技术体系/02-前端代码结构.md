# 前端代码结构

## 概述

`D:\Projects\SAAS\frontend` 采用 Vue 3 + TypeScript + Vite 技术栈，Naive UI 组件库，Pinia 状态管理，Vue Router 路由管理。目录按视图页面组织。

## 顶层目录

| 目录 | 作用 |
| --- | --- |
| `api/` | Axios 封装，统一拦截器 |
| `assets/` | 静态资源 |
| `components/` | 公共组件 |
| `composables/` | Composition API 逻辑复用 |
| `config/` | 前端配置 |
| `constants/` | 业务常量 |
| `router/` | Vue Router 路由定义与守卫 |
| `stores/` | Pinia Store（按业务模块组织） |
| `styles/` | 全局样式 |
| `theme/` | Naive UI 主题定制 |
| `types/` | TypeScript 类型声明 |
| `utils/` | 工具函数 |
| `views/` | 页面组件（按业务模块组织） |

## views/ 页面目录

| 视图 | 关联领域 |
| --- | --- |
| `dashboard/` | 分析模块 |
| `data/` | 分析/数据报表 |
| `dev/` | 调试（seed、测试） |
| `layout/` | 布局组件 |
| `ops/` | 运维（日志） |
| `orders/` | 订单域 |
| `product/` | 商品域 |
| `profile/` | 用户（个人中心） |
| `sample/` | 寄样域 |
| `system/` | 用户域（用户/角色/菜单） |
| `talent/` | 达人域 |
