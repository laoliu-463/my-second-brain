# 前后端映射

## 概述

前后端通过 REST API 交互，前端 `src/api/*.ts` 调用后端 Controller 接口，实现七领域业务闭环。

## API 映射总表

| 前端 API 文件 | 后端 Controller | 路径前缀 | 关联领域 |
| --- | --- | --- | --- |
| `auth.ts` | AuthController | `/api/auth` | 认证 |
| `sys.ts` | SystemController | `/api/system` | 用户域 |
| `product.ts` | ProductController | `/api/product` | 商品域 |
| `activityProduct.ts` | ActivityProductController | `/api/activity-product` | 商品域-活动商品 |
| `activity.ts` | ActivityController | `/api/activity` | 商品域-活动 |
| `talent.ts` | TalentController | `/api/talent` | 达人域 |
| `sample.ts` | SampleController | `/api/sample` | 寄样域 |
| `order.ts` | OrderController | `/api/order` | 订单域 |
| `commission.ts` | CommissionController | `/api/commission` | 业绩域-佣金 |
| `performance.ts` | PerformanceController | `/api/performance` | 业绩域 |
| `data.ts` | DataController | `/api/data` | 分析模块 |
| `dashboard.ts` | DashboardController | `/api/dashboard` | 分析模块-看板 |
| `ruleCenter.ts` | RuleCenterController | `/api/rule-center` | 配置域 |
| `douyin.ts` | DouyinController | `/api/douyin` | 第三方对接 |

## 数据流

```
前端 views → API 调用 → Controller → Service → Domain/Entity → Mapper → PostgreSQL
                ↓
           Redis（缓存/会话）
```
