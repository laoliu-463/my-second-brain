# 活动商品同步

## 概述

从抖店侧同步活动商品，落入商品域，支撑招商和渠道推广。

## 数据流

1. 管理端或同步任务触发活动商品同步
2. 后端 Gateway 调用第三方接口
3. 商品域标准化字段并入库
4. 前端通过内部 API 查询商品

## 验收证据

- 第三方请求/响应摘要
- 商品表或商品 API 返回同步商品
- real-pre 空数据必须记录真实响应，不手工伪造
