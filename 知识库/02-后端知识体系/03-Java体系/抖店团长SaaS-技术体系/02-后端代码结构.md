# 后端代码结构

## 概述

`D:\Projects\SAAS\backend` 采用 Spring Boot 模块化单体架构，Java 包按技术分层组织，对应七领域文档中的领域职责。

## 顶层包结构

| 包路径 | 作用 | 关联领域 |
| --- | --- | --- |
| `annotation/` | 自定义注解（@RequireRoles、@DataScope 等权限注解） | 用户域 |
| `aspect/` | AOP 切面（日志拦截、操作审计） | 配置域 |
| `auth/` | 认证模块（JWT、登录、Token） | 用户域 |
| `common/` | 通用工具、响应封装、常量 | 通用 |
| `config/` | Spring 配置类（Security、Redis、Web 等） | 通用 |
| `constant/` | 常量定义 | 通用 |
| `controller/` | REST 控制器（按领域分组） | API 入口 |
| `crawler/` | 爬虫相关（达人信息采集） | 达人域 |
| `debug/` | 调试接口（seed、reset） | 工具 |
| `domain/` | 领域层（事件、产品、样品、用户） | 七领域 |
| `douyin/` | 抖店 SDK 封装、API 调用 | 第三方对接 |
| `dto/` | 数据传输对象 | API 层 |
| `entity/` | 数据库实体（MyBatis-Plus） | 数据模型 |
| `event/` | Spring 事件定义与监听 | 事件契约 |
| `gateway/` | API 网关、路由 | 第三方对接 |
| `job/` | 定时任务（样品超时关闭、订单同步） | 订单域 |
| `listener/` | 事件监听器 | 事件契约 |
| `mapper/` | MyBatis-Plus Mapper 接口 | 数据访问 |
| `security/` | 安全相关（Filter、加密） | 用户域 |
| `service/` | 服务层（含 impl 实现） | 业务逻辑 |
| `testsupport/` | 测试辅助（Mock 数据、Fixtures） | 测试 |
| `util/` | 工具类 | 通用 |
| `vo/` | 视图对象（API 响应） | API 层 |

## domain/ 领域包

| 子包 | 关联领域 |
| --- | --- |
| `domain/event/` | 事件 |
| `domain/product/` | 商品域 |
| `domain/sample/` | 寄样域 |
| `domain/user/` | 用户域 |

## service/ 服务包

| 子包 | 作用 |
| --- | --- |
| `service/data/` | 数据分析/业绩相关 |
| `service/display/` | 展示/看板 |
| `service/impl/` | 业务逻辑实现 |
| `service/performance/` | 业绩计算 |
| `service/sample/` | 寄样服务 |
| `service/talent/` | 达人服务 |

## 技术栈证据

| 项 | 事实 |
| --- | --- |
| 框架 | Spring Boot 3.2.5 |
| Java | Java 17 |
| ORM | MyBatis-Plus |
| 数据库 | PostgreSQL |
| 认证 | JWT + Spring Security |
| API 文档 | Knife4j |
| 测试 | JUnit 5 + Mockito + AssertJ + Testcontainers |
| 覆盖率 | JaCoCo 80% 门槛 |
