# 测试验收

## 概述

每个验收项必须对应脚本、API/SQL 或证据路径。test/mock 证据只能证明本地闭环，不能替代 real-pre。

## 脚本入口

| 命令 | 用途 |
| --- | --- |
| `npm run e2e:v1-p0` | V1 P0 浏览器验收 |
| `npm run e2e:real-pre:p0:preflight` | real-pre 预检 |
| `npm run e2e:real-pre:p0` | real-pre P0 联调验收 |
| `npm run e2e:real-pre:roles` | real-pre 角色权限回归 |
| `cd backend; mvn test` | 后端单元/集成测试 |
| `cd frontend; npm run build` | 前端构建验证 |

## 状态分类

| 状态 | 含义 | 是否可收口 |
| --- | --- | --- |
| PASS | 验收通过且证据完整 | 是 |
| PASS_NEEDS_CLEANUP | 主链路通过，但有清理项 | 条件通过 |
| BLOCKED | 受外部 Token、权限包、真实样本等阻塞 | 否，需证据 |
| PENDING | 未执行或证据不足 | 否 |
| FAIL | 已复现失败 | 否，需缺陷单 |
