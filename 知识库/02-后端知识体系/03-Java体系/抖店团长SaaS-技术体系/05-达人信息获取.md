# 达人信息获取

## 概述

在权限允许时从第三方补充达人资料。系统内达人资料、标签、地址和跟进能力必须可用。

## 核心事实

- 达人域负责达人资料事实
- 第三方达人信息获取受权限包和接口稳定性约束，可记录 BLOCKED
- 旧 `Python + requests + fake-useragent` 采集方案不是当前事实

## 数据流

1. 系统内维护达人基础资料
2. 如第三方权限可用，Gateway 获取达人补充字段
3. 达人域保存来源、更新时间和关键字段
