# 部署运行

## 概述

当前运行以 Docker Compose 管理 PostgreSQL、Redis、后端和前端。real-pre 必须关闭 mock。

## 环境清单

| 环境 | Compose/配置 | 用途 |
| --- | --- | --- |
| test | `docker-compose.test.yml`、`.env.test` | 本地 mock/P0 回归 |
| real-pre | `docker-compose.real-pre.yml`、`.env.real-pre` | 真实联调、上线前验收 |

## 端口约束

| 用途 | 前端 | 后端 | 数据库 | Redis |
| --- | --- | --- | --- | --- |
| test | 3000 | 8080 | 5432 | 6379 |
| real-pre | 3001 | 8081 | 5433 | 6380 |

## real-pre 关键约束

| 配置 | 说明 |
| --- | --- |
| `APP_TEST_ENABLED=false` | 关闭应用层 mock |
| `DOUYIN_TEST_ENABLED=false` | 关闭抖店 mock |
| `DOUYIN_REAL_UPSTREAM_MODE=live` | 切换到真实上游 |
| `DOUYIN_REAL_PROMOTION_WRITE_ENABLED=false` | 默认禁止真实推广写 |
| `ALLOW_REAL_PROMOTION_WRITE=false` | 双开关控制 |
