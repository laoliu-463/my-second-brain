# 数据模型

## 概述

数据表字段级事实以数据库迁移、实体类和 SQL 查询结果为准。

## 核心原则

- 订单域只存事实，不计算提成
- 业绩域负责最终归属、提成、冲正
- 分析模块只读汇总表，不重算业绩归属

## 数据模型总表

| 模型/表族 | 所属领域 | 存储事实 | 禁止承载 |
| --- | --- | --- | --- |
| 用户、角色、组织、菜单 | 用户域 | 用户身份、权限、组织和菜单 | 业务归属计算 |
| 配置、规则、变更日志 | 配置域 | 配置值、规则参数、变更审计 | 具体业务执行 |
| 商品库、活动商品 | 商品域 | 商品、活动、价格、佣金展示输入 | 最终业绩 |
| `pick_source_mapping` | 商品域 | 转链结果、达人/商品/渠道映射 | 最终提成结论 |
| 达人、标签、地址、关系 | 达人域 | 达人基础资料、标签、地址、渠道关系 | 订单最终归属 |
| 寄样申请、寄样状态 | 寄样域 | 申请、审批、发货、交作业状态 | 业绩计算 |
| 订单、订单明细 | 订单域 | 抖店订单事实、支付金额、商品、时间 | 提成、独家覆盖 |
| 退款/售后 | 订单域 | 退款事实、售后状态、退款金额 | 冲正结果 |
| 业绩明细 | 业绩域 | 最终归属、提成、冲正、双轨金额 | 第三方原始事实采集 |
| 业绩汇总 | 业绩域 | 按人、组织、周期的汇总结果 | 重新归因逻辑 |
| 分析快照/报表 | 分析模块 | 只读汇总、导出快照 | 修改订单或业绩事实 |
| Outbox/事件记录 | 基础设施 | 事件投递事实、状态、重试 | 业务事实唯一来源 |
