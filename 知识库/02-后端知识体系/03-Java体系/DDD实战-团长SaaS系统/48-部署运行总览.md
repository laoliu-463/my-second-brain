# 部署运行总览

## 概述

当前运行以 Docker Compose 管理 PostgreSQL、Redis、后端和前端。real-pre 必须关闭 mock，不允许用 test/mock 基线冒充真实闭环。2026-05-28 release 审查结论是“可受控部署”，不能写成“正式生产全量上线”。

## 当前运行口径

- Docker Compose 管理 PostgreSQL、Redis、后端和前端
- 本机常用端口组：`3000/8080`（test）与 `3001/8081`（real-pre），不得混起
- real-pre 必须关闭 mock：`APP_TEST_ENABLED=false`、`DOUYIN_TEST_ENABLED=false`
- 只保留两个环境：test 测试环境与 real-pre 真实上游/生产形态环境

## 环境清单

| 环境 | Compose/配置 | 用途 | 验证 |
| --- | --- | --- | --- |
| test | `docker-compose.test.yml`、`.env.test` | 本地 mock/P0 回归 | E2E、API、SQL |
| real-pre | `docker-compose.real-pre.yml`、`.env.real-pre` | 真实联调、上线前验收和当前生产形态部署 | preflight、真实接口、日志、迁移记录 |

## real-pre 关键约束

| 配置 | 说明 |
| --- | --- |
| `APP_TEST_ENABLED=false` | 必须关闭应用层 mock |
| `DOUYIN_TEST_ENABLED=false` | 必须关闭抖店 mock |
| `DOUYIN_REAL_UPSTREAM_MODE=live` | 切换到真实上游 |
| `DOUYIN_REAL_PROMOTION_WRITE_ENABLED=false` | 默认禁止真实推广写操作 |
| `ALLOW_REAL_PROMOTION_WRITE=false` | 双开关控制，人工批准窗口才开启 |

## 服务器部署目录结构

```
/opt/saas/
├── app/         # 应用代码
├── env/         # 环境变量（.env.real-pre）
├── logs/        # 日志
├── backups/     # 数据库备份
└── runtime/qa/out/  # QA 证据输出
```

## 明确不做

- 不把旧 FastAPI/Celery 部署方案写为当前部署事实
- 不使用 mock 数据证明 real-pre 闭环
- 不再维护独立 `prod`/`production` 环境入口；生产形态统一进入 `real-pre`
