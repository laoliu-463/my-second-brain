# 后端代码结构索引

## 概述

`D:\Projects\SAAS\backend` 采用 Spring Boot 模块化单体架构，Java 包按技术分层组织。主要包含 controller、service、domain、entity、mapper、dto 等包，与项目七领域文档对应。

| 包路径 | 作用 | 关联领域/文档 |
| --- | --- | --- |

## 领域包详解

### domain/ 领域包

| 子包 | 关联领域 | 主要类 |
| --- | --- | --- |
| `domain/event/` | 事件 | OrderSyncedEvent、SampleDeliveredEvent 等 |
| `domain/product/` | 商品域 | Product 相关领域模型 |
| `domain/sample/` | 寄样域 | Sample 相关领域模型 |
| `domain/user/` | 用户域 | User、Role、Org 相关 |

### service/ 服务包

| 子包 | 作用 |
| --- | --- |

| `service/display/` | 展示/看板相关服务 |
| `service/impl/` | 服务实现（业务逻辑层） |
| `service/performance/` | 业绩计算服务 |
| `service/sample/` | 寄样服务 |
| `service/talent/` | 达人服务 |

## 技术栈证据

- **框架**: Spring Boot 3.2.5
- **Java 版本**: Java 17
- **ORM**: MyBatis-Plus
- **数据库**: PostgreSQL
- **缓存**: Redis
- **认证**: JWT + Spring Security
- **API 文档**: Knife4j
- **测试**: JUnit 5 + Mockito + AssertJ + Testcontainers
- **覆盖率**: JaCoCo 80% 门槛
