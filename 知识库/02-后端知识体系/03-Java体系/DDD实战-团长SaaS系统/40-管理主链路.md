# 管理主链路

## 概述

管理员能配置规则、管理用户权限、查看审计和验收关键看板。管理动作必须留下可追溯证据。

## 参与角色

管理员、主管、运维，涉及：用户域、配置域、分析模块、各业务域审计入口

## 主流程

1. 管理员登录并获取管理菜单
2. 管理员维护用户、角色、组织和菜单
3. 管理员维护配置和规则参数
4. 配置域记录配置变更日志
5. 管理员查看订单、业绩、寄样和 dashboard 汇总
6. 管理员导出或记录验收证据

## 异常与分支

- 低权限账号尝试管理操作时必须被后端拒绝
- 配置变更失败必须返回明确错误，不产生半更新
- 操作日志以关键操作覆盖为主，完整审计湖进入 V2

## 关键数据与事件

| 类型 | 内容 |
| --- | --- |
| 关键数据 | 用户、角色、菜单、配置、配置变更日志、操作日志、汇总表 |
| 关键事件 | 用户权限已变更、配置已变更、业绩汇总已刷新 |

## 验收证据

- 管理员和普通用户同页面权限差异可通过 E2E 证明
- 配置变更有 API 响应、数据库记录和操作日志
