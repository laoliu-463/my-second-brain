# 分析模块领域合同

## 领域定位

分析模块负责 Dashboard、报表、导出和只读汇总展示，**只读汇总表，不重算业绩归属**。

## 职责边界

| 类型 | 内容 |
| --- | --- |
| 负责 | Dashboard、报表、趋势、导出 |
| 负责 | 按用户数据范围读取汇总 |
| 不负责 | 订单同步、归因、提成、冲正 |
| 不负责 | 修改订单、寄样、业绩事实 |

## 核心事实

- 分析模块消费业绩域和订单域已形成的汇总或事实查询
- 分析模块不得通过重新扫描订单来产生新的最终归属
- 分析模块读取汇总表、报表快照和导出结果，不写订单最终归属、不写业绩明细

## 对外能力

| 能力 | 使用方 | 证据 |
| --- | --- | --- |
| Dashboard 汇总 | 管理端、渠道端 | dashboard API、E2E |
| 报表查询 | 管理端 | API/SQL 对比 |
| 导出 | 管理端 | 导出文件、操作日志 |

## 事件契约

| 事件 | 触发 | 消费方 |
| --- | --- | --- |
| 业绩汇总已刷新 | 业绩域刷新汇总 | 分析模块读取 |
| 分析快照已生成 | 报表生成 | 前端、验收 |
