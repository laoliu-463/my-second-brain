# 商品域领域合同

## 领域定位

商品域负责商品库、活动商品、商品展示输入、转链和 `pick_source_mapping`，为订单归因提供映射事实，**不计算最终业绩和提成**。

## 职责边界

| 类型 | 内容 |
| --- | --- |
| 负责 | 商品库、活动商品同步、筛选、展示规则输入 |
| 负责 | 抖音转链、`pick_source_mapping` 落库 |
| 负责 | quick sample 等内部寄样申请入口的商品上下文 |
| 不负责 | 订单最终归属、提成、冲正 |
| 不负责 | 分析看板重算业绩 |

## 核心事实

- 调用转链能力后必须落 `pick_source_mapping`
- `pick_source_mapping` 至少能支撑商品、达人/渠道、pick source、时间和第三方响应追溯
- real-pre 转链必须保存真实请求/响应或阻塞证据

## 对外能力

| 能力 | 使用方 | 证据 |
| --- | --- | --- |
| 商品库查询 | 前端、招商、渠道 | 商品 API、E2E |
| 活动商品同步 | 招商、管理 | 同步日志、商品表 |
| 转链 | 渠道、达人链路 | 第三方响应、`pick_source_mapping` |
| 商品寄样入口 | 寄样域 | 寄样申请记录 |

## 事件契约

| 事件 | 触发 | 消费方 |
| --- | --- | --- |
| 商品已同步 | 活动商品或商品库同步成功 | 分析模块、商品列表 |
| 商品转链已完成 | 转链成功并落库 | 订单域、业绩域 |
