# 业绩计算链路

## 概述

基于订单事实、商品映射、达人关系和配置，计算最终归属、提成、冲正和双轨金额。输出业绩明细和汇总，供分析模块只读。

## 参与角色

业绩域、订单域、商品域、达人域、配置域、分析模块

## 主流程

1. 业绩域消费订单已同步事件或按任务扫描待计算订单事实
2. 业绩域读取商品映射、达人关系和配置版本
3. 业绩域执行最终归属和独家覆盖规则
4. 业绩域计算提成、毛利、双轨金额
5. 业绩域处理退款/售后事实产生冲正
6. 业绩域刷新汇总表
7. 分析模块读取汇总并展示

## 异常与分支

- 输入缺失时写入待处理或异常原因，不静默吞掉订单
- 规则配置缺失时返回可追踪错误
- 订单域、配置域、分析模块不得代替业绩域完成最终计算

## 关键数据与事件

| 类型 | 内容 |
| --- | --- |
| 关键数据 | 订单事实、退款事实、`pick_source_mapping`、配置版本、业绩明细、汇总表 |
| 关键事件 | 订单已同步、退款事实已同步、业绩归属已计算、业绩汇总已刷新 |

## 验收证据

- 单笔订单可从订单事实追溯到业绩明细
- 单笔退款可追溯到冲正结果
- dashboard 汇总能与业绩汇总表对账
