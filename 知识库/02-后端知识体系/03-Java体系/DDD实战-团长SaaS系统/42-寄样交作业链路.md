# 寄样交作业链路

## 概述

寄样从申请、审批、发货到交作业完成形成可验证闭环。交作业完成以订单已同步事件为核心证据。

## 参与角色

渠道、招商、管理员，涉及：寄样域、达人域、商品域、订单域、分析模块

## 主流程

1. 渠道或招商基于商品和达人发起寄样申请
2. 管理端审批寄样申请
3. 管理端发货并记录物流信息
4. 订单域同步相关订单事实
5. 寄样域消费订单已同步事件，判断交作业完成
6. 分析模块读取寄样状态和汇总展示

## 异常与分支

- 没有订单同步证据时，不得把交作业标为真实完成
- 物流接口不可用时可用手工物流事实，但需保留来源

## 关键数据与事件

| 类型 | 内容 |
| --- | --- |
| 关键数据 | 寄样申请、达人地址、物流单、订单事实、寄样状态 |
| 关键事件 | 寄样状态已变更、订单已同步 |

## 验收证据

- E2E 覆盖申请、审批、发货、订单回流后的状态变化
- SQL/API 能证明状态变化来源于订单已同步事件
