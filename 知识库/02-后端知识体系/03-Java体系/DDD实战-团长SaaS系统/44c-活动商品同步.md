# 活动商品同步

## 概述

从抖音/抖店侧同步活动商品，落入商品域，支撑招商和渠道推广。同步结果必须能通过商品 API、数据库和日志验证。

## 核心事实

- 活动商品同步属于商品域能力
- 第三方字段进入内部模型时必须保留来源和必要原始标识
- V1 优先保证 P0 商品字段、筛选、列表和转链所需字段

## 数据流

1. 管理端或同步任务触发活动商品同步
2. 后端 Gateway 调用第三方接口
3. 商品域标准化字段并入库
4. 前端通过内部 API 查询商品
5. 验收通过 API/SQL/日志证明数据来自同步结果

## 验收证据

- 第三方请求/响应摘要
- 商品表或商品 API 返回同步商品
- 商品列表 E2E 可展示同步结果
- real-pre 空数据必须记录真实响应，不手工伪造

## 明确不做

- 不让前端直接调用第三方商品接口
- 不把 mock 商品作为 real-pre 同步成功证据
