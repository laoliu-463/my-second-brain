# 寄样域领域合同

## 领域定位

寄样域负责寄样申请、审批、发货、物流、收货和交作业状态，**通过订单已同步事件判断交作业完成**。

## 职责边界

| 类型 | 内容 |
| --- | --- |
| 负责 | 寄样申请、审批、发货、状态机、操作日志 |
| 负责 | 基于订单已同步事实判断交作业完成 |
| 不负责 | 订单事实同步 |
| 不负责 | 业绩归属、提成、冲正 |

## 核心事实

- 交作业完成判断必须以订单域发布的订单已同步事实为证据
- 寄样状态变更必须有操作者、时间、前后状态
- 寄样域保存订单关联结果，但订单原始事实仍属于订单域

## 对外能力

| 能力 | 使用方 | 证据 |
| --- | --- | --- |
| 寄样申请 | 渠道、招商 | 寄样 API、E2E |
| 审批/发货 | 管理端、招商 | 状态日志、物流信息 |
| 交作业判断 | 订单域、寄样域 | 订单已同步事件、寄样状态 |
| 导出/看板 | 管理端、分析模块 | 导出文件、汇总 API |

## 事件契约

| 事件 | 触发 | 消费方 |
| --- | --- | --- |
| 寄样状态已变更 | 申请、审批、发货、作业状态变化 | 分析模块、审计 |
| 订单已同步 | 订单域同步订单事实 | 寄样域判断交作业 |
