# 用户域领域合同

## 领域定位

用户域负责用户、角色、组织、菜单和统一数据范围，对其他业务域提供 `self/group/all` 数据范围，**不替业务域判断订单归属、业绩归属或业务状态**。

## 职责边界

| 类型 | 内容 |
| --- | --- |
| 负责 | 登录用户上下文、角色、组织、菜单、数据范围解析 |
| 负责 | 管理员、主管、普通渠道等角色的权限基础 |
| 不负责 | 商品、订单、寄样、业绩的业务状态机 |
| 不负责 | 订单最终归属、提成、独家覆盖 |

## 核心事实

- 数据范围统一抽象为 `self/group/all`
- 其他领域查询必须能追溯当前用户、角色、组织和数据范围来源
- V1 以当前权限注解、后端查询过滤和 E2E 证据为主

## 数据范围定义

| 范围 | 含义 | 典型使用 |
| --- | --- | --- |
| `self` | 仅当前用户负责的数据 | 渠道个人商品、达人、订单、寄样 |
| `group` | 当前组织或团队范围 | 主管查看组内订单、业绩 |
| `all` | 管理员或授权全量范围 | 管理端看板、审计、配置 |

## 对外能力

| 能力 | 使用方 | 证据 |
| --- | --- | --- |
| 当前用户信息 | 前端、业务域 | `/api/auth/me` |
| 用户/角色/菜单管理 | 管理端 | 用户、角色、菜单 API |
| 数据范围解析 | 商品、达人、寄样、订单、业绩、分析 | 权限测试、API/SQL 对比 |

## 事件契约

| 事件 | 触发 | 消费方 |
| --- | --- | --- |
| 用户数据范围已解析 | 查询上下文建立 | 各业务域查询侧 |
| 用户权限已变更 | 角色、菜单或组织变更 | 审计、缓存失效 |
