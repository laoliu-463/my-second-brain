# 第三方对接总览

## 概述

前端只调用内部 API，后端 Gateway/SDK 负责抖音/抖店接口封装、鉴权、参数转换、签名、错误码适配和响应标准化。real-pre 验收必须使用真实 Token、真实配置和真实接口响应。

## 总原则

- 前端只调用内部 API
- 后端 Gateway/SDK 负责抖音/抖店接口封装、鉴权、参数转换、签名、错误码适配和响应标准化
- real-pre 验收必须使用真实 Token、真实配置和真实接口响应，不得用 mock 数据冒充
- 缺权限包、缺真实样本、触发限流的分支可记录为 BLOCKED，但必须保留请求、响应、时间和环境证据
