# 配置域领域合同

## 领域定位

配置域负责配置项、规则参数、配置变更日志和配置查询，**只提供配置事实，不执行具体业务规则**。

## 职责边界

| 类型 | 内容 |
| --- | --- |
| 负责 | 配置读取、保存、校验、审计 |
| 负责 | 佣金规则参数、业务开关、展示规则参数 |
| 不负责 | 商品转链、订单归因、提成计算、寄样状态流转 |
| 不负责 | 直接触发业务动作 |

## 核心事实

- 规则执行属于读取配置的业务域，例如业绩域负责提成和冲正计算
- 配置变更必须有操作者、变更前后值和时间
- 业务执行结果不写入配置域

## 对外能力

| 能力 | 使用方 | 证据 |
| --- | --- | --- |
| 配置读取 | 商品、订单、业绩、分析 | 配置 API |
| 配置修改 | 管理端 | 配置变更日志 |
| 规则参数查询 | 业绩域、商品域 | 规则中心 API |

## 事件契约

| 事件 | 触发 | 消费方 |
| --- | --- | --- |
| 配置已变更 | 配置保存成功 | 缓存失效、审计、业务域后续读取 |
