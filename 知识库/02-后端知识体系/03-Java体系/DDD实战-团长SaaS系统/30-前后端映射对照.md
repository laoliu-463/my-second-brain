# 前后端映射对照

## 概述

前后端通过 REST API 交互，前端 `src/api/*.ts` 调用后端 Controller 接口，实现七领域业务闭环。

## API 映射总表

| 前端 API 文件 | 后端 Controller | 路径前缀 | 关联领域 |
| --- | --- | --- | --- |
| `api/auth.ts` | AuthController | `/api/auth` | 认证 |
| `api/sys.ts` | SystemController | `/api/system` | 系统（用户/角色/菜单） |
| `api/product.ts` | ProductController | `/api/product` | 商品域 |
| `api/activityProduct.ts` | ActivityProductController | `/api/activity-product` | 商品域-活动商品 |
| `api/activity.ts` | ActivityController | `/api/activity` | 商品域-活动 |
| `api/talent.ts` | TalentController | `/api/talent` | 达人域 |
| `api/sample.ts` | SampleController | `/api/sample` | 寄样域 |
| `api/order.ts` | OrderController | `/api/order` | 订单域 |
| `api/commission.ts` | CommissionController | `/api/commission` | 业绩域-佣金 |
| `api/performance.ts` | PerformanceController | `/api/performance` | 业绩域 |
| `api/data.ts` | DataController | `/api/data` | 分析模块 |
| `api/dashboard.ts` | DashboardController | `/api/dashboard` | 分析模块-看板 |
| `api/ruleCenter.ts` | RuleCenterController | `/api/rule-center` | 配置域 |
| `api/douyin.ts` | DouyinController | `/api/douyin` | 第三方对接 |

## 七领域映射

### 用户域

| 前端 | 后端 | 功能 |
| --- | --- | --- |
| `api/sys.ts` | SystemController | 用户管理、角色管理、组织管理、菜单管理 |
| `api/auth.ts` | AuthController | 登录、Token 刷新 |

### 配置域

| 前端 | 后端 | 功能 |
| --- | --- | --- |
| `api/ruleCenter.ts` | RuleCenterController | 规则配置、参数管理 |

### 商品域

| 前端 | 后端 | 功能 |
| --- | --- | --- |
| `api/product.ts` | ProductController | 商品库管理 |
| `api/activity.ts` | ActivityController | 活动管理 |
| `api/activityProduct.ts` | ActivityProductController | 活动商品关联、转链 |

### 达人域

| 前端 | 后端 | 功能 |
| --- | --- | --- |
| `api/talent.ts` | TalentController | 达人资料、标签、地址、渠道关系 |

### 寄样域

| 前端 | 后端 | 功能 |
| --- | --- | --- |
| `api/sample.ts` | SampleController | 寄样申请、审核、发货、签收 |

### 订单域

| 前端 | 后端 | 功能 |
| --- | --- | --- |
| `api/order.ts` | OrderController | 订单列表、订单详情、退款 |

### 业绩域

| 前端 | 后端 | 功能 |
| --- | --- | --- |
| `api/commission.ts` | CommissionController | 佣金计算、结算 |
| `api/performance.ts` | PerformanceController | 业绩统计、汇总 |

### 分析模块

| 前端 | 后端 | 功能 |
| --- | --- | --- |
| `api/dashboard.ts` | DashboardController | Dashboard 看板 |
| `api/data.ts` | DataController | 数据报表、汇总 |

## 前端视图与 API 映射

| 视图目录 | 调用 API | 关联领域 |
| --- | --- | --- |
| `views/dashboard/` | `api/dashboard.ts` | 分析模块-看板 |
| `views/data/` | `api/data.ts` | 分析模块-报表 |
| `views/orders/` | `api/order.ts` | 订单域 |
| `views/product/` | `api/product.ts`, `api/activity.ts`, `api/activityProduct.ts` | 商品域 |
| `views/sample/` | `api/sample.ts` | 寄样域 |
| `views/talent/` | `api/talent.ts` | 达人域 |
| `views/system/` | `api/sys.ts` | 用户域 |
| `views/ops/` | `api/sys.ts` | 运维（日志） |

## 数据流闭环

```
前端 views → API 调用 → Controller → Service → Domain/Entity → Mapper → PostgreSQL
                ↓
           Redis (缓存/会话)
```
