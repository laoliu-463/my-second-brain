# 渠道主链路

## 概述

渠道用户能在自身数据范围内查看商品、转链、跟进达人、申请寄样、查看订单和业绩。全流程受用户域 `self/group/all` 数据范围约束。

## 参与角色

普通渠道、渠道主管、管理员，涉及：商品域、达人域、寄样域、订单域、业绩域、分析模块、用户域

## 主流程

1. 渠道登录系统，用户域返回当前用户和数据范围
2. 渠道按范围查看商品列表
3. 渠道对商品执行转链，商品域落 `pick_source_mapping`
4. 渠道维护达人资料、跟进或寄样申请
5. 订单域同步订单事实，保留 `pick_source` 等归因输入
6. 业绩域根据订单事实、映射、达人关系和配置计算最终归属
7. 分析模块只读汇总，展示渠道业绩

## 异常与分支

- 转链失败时必须保留第三方错误码和请求上下文
- 订单未回流时不能伪造业绩结论，只能标记待同步或阻塞
- 缺达人外部信息时可使用系统内达人资料，但需标记来源
- 前端不得绕过后端权限直接展示他人订单或业绩

## 关键数据与事件

| 类型 | 内容 |
| --- | --- |
| 关键数据 | 用户数据范围、商品、`pick_source_mapping`、达人、寄样、订单事实、业绩明细、业绩汇总 |
| 关键事件 | 商品转链已完成、订单已同步、业绩归属已计算、业绩汇总已刷新 |

## 验收证据

- `npm run e2e:v1-p0` 覆盖渠道主链路
- API/SQL 证明不同账号的数据范围差异
- 转链记录、订单事实、业绩汇总可串联
