# 物流接口

## 概述

支撑寄样发货、物流单号记录和必要的物流查询。真实物流接口不可用时，必须记录权限、样本或接口阻塞证据。

## 核心事实

- 寄样域负责寄样物流事实和状态流转
- V1 可采用手工物流事实 + 第三方接口阻塞证据的组合

## 数据流

1. 寄样审批通过后进入发货
2. 管理端录入或接口获取物流单号
3. 如有接口权限，则 Gateway 调用物流接口查询状态
4. 寄样域记录物流事实和状态变更

## 验收证据

- 发货操作有 API 响应和寄样状态记录
- 真实物流接口有请求/响应或 BLOCKED 证据
- 不使用无法追溯的页面文字替代数据库或接口证据

## 明确不做

- 不把物流接口缺失包装成已完成真实对接
