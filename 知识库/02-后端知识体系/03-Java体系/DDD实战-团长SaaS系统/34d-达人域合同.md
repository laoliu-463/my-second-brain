# 达人域领域合同

## 领域定位

达人域负责达人资料、标签、地址、跟进和渠道关系，向寄样、商品和业绩链路提供达人事实，**不替代订单域或业绩域做最终归属**。

## 职责边界

| 类型 | 内容 |
| --- | --- |
| 负责 | 达人基础资料、标签、地址、跟进记录 |
| 负责 | 达人与渠道、商品、寄样的关系事实 |
| 不负责 | 订单事实采集和订单归属计算 |
| 不负责 | 提成、冲正、双轨金额 |

## 核心事实

- 达人信息必须可支撑寄样、跟进、渠道协作和业绩归属输入
- 达人域可保存外部接口返回字段，但必须标记来源和更新时间
- 旧文档中的 `Python + requests + fake-useragent` 采集方案不是当前事实

## 对外能力

| 能力 | 使用方 | 证据 |
| --- | --- | --- |
| 达人列表/详情 | 前端、寄样、招商 | 达人 API、E2E |
| 标签和跟进 | 渠道、招商、管理 | 操作日志、列表筛选 |
| 达人地址 | 寄样域 | 地址记录、寄样发货 |
| 第三方达人补充 | 管理端 | real-pre 响应或阻塞证据 |

## 事件契约

| 事件 | 触发 | 消费方 |
| --- | --- | --- |
| 达人资料已更新 | 资料、标签、地址、关系变更 | 寄样域、分析模块 |
