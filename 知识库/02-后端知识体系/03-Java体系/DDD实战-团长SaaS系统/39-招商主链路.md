# 招商主链路

## 概述

招商角色能维护活动商品、达人合作、寄样推进和订单转化证据。招商链路输出的商品、达人、寄样、订单事实能被业绩域消费。

## 参与角色

招商、渠道、管理员，涉及：商品域、达人域、寄样域、订单域、业绩域、配置域

## 主流程

1. 招商同步或维护活动商品
2. 招商维护达人资料、标签、地址和跟进记录
3. 招商或渠道发起寄样申请
4. 管理端完成审批和发货
5. 商品转链形成 `pick_source_mapping`
6. 订单域同步订单事实
7. 业绩域计算最终归属和提成

## 异常与分支

- 活动商品为空时记录第三方响应，不伪造商品
- 达人接口无权限时记录 BLOCKED 证据
- 物流接口缺真实样本时允许手工录入物流事实，但必须标记来源

## 关键数据与事件

| 类型 | 内容 |
| --- | --- |
| 关键数据 | 活动商品、达人资料、达人地址、寄样申请、映射、订单事实、业绩结果 |
| 关键事件 | 商品已同步、达人资料已更新、寄样状态已变更、订单已同步 |

## 验收证据

- 商品同步日志和商品表可查
- 达人、寄样、订单、业绩之间能通过 API/SQL 串联
- real-pre 对接项必须落入验收证据索引
