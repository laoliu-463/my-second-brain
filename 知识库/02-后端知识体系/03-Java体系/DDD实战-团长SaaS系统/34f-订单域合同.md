# 订单域领域合同

## 领域定位

订单域负责订单事实、订单明细、退款/售后事实和归因输入，**只存事实，不算提成，不应用独家覆盖**。

## 职责边界

| 类型 | 内容 |
| --- | --- |
| 负责 | 抖店订单同步、订单入库、退款事实、幂等 |
| 负责 | 保存 `pick_source` 等归因输入 |
| 负责 | 发布订单已同步、退款事实已同步事件 |
| 不负责 | 最终归属、提成、冲正、双轨金额 |
| 不负责 | 独家覆盖规则执行 |

## 核心事实

- 订单域是订单事实来源，不是业绩结论来源
- 订单同步必须具备幂等键、时间窗口、同步日志和错误证据
- 退款事实必须独立保存，供业绩域处理冲正
- 旧文档中的 Celery 定时任务不是当前运行事实

## 对外能力

| 能力 | 使用方 | 证据 |
| --- | --- | --- |
| 订单同步 | 管理端、调度 | 第三方响应、订单表、同步日志 |
| 订单查询 | 前端、业绩域、分析模块 | 订单 API、数据范围测试 |
| 退款同步 | 业绩域、分析模块 | 退款表、同步日志 |
| 订单事件 | 寄样域、业绩域 | 事件日志、消费结果 |

## 事件契约

| 事件 | 触发 | 消费方 |
| --- | --- | --- |
| 订单已同步 | 订单事实同步入库 | 寄样域、业绩域、分析模块 |
| 退款事实已同步 | 退款/售后事实同步入库 | 业绩域、分析模块 |
