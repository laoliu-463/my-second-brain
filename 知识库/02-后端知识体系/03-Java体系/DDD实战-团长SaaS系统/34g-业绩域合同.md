# 业绩域领域合同

## 领域定位

业绩域负责**最终归属、提成、冲正和双轨金额计算**。消费订单事实、商品映射、达人关系和配置参数，输出业绩明细与汇总。

## 职责边界

| 类型 | 内容 |
| --- | --- |
| 负责 | 最终归属、提成、冲正、双轨金额 |
| 负责 | 独家覆盖规则执行 |
| 负责 | 汇总表刷新，供分析模块只读 |
| 不负责 | 抖店订单原始事实同步 |
| 不负责 | 商品转链和 `pick_source_mapping` 生成 |

## 核心事实

- 业绩域是最终归属结论来源
- 订单域只提供订单事实，配置域只提供规则参数，业绩域负责执行规则
- 双轨金额、提成和毛利口径必须可审计
- 必须保留输入来源，支持追溯订单、商品映射、达人关系和配置版本

## 对外能力

| 能力 | 使用方 | 证据 |
| --- | --- | --- |
| 业绩计算 | 管理端、调度 | 计算日志、业绩明细表 |
| 冲正处理 | 管理端、分析模块 | 退款事实、冲正记录 |
| 汇总刷新 | 分析模块、dashboard | 汇总表、看板 API |
| 规则读取 | 配置域 | 配置 API、规则中心 |

## 事件契约

| 事件 | 触发 | 消费方 |
| --- | --- | --- |
| 订单已同步 | 订单域入库订单事实 | 业绩域计算归属 |
| 退款事实已同步 | 订单域入库退款事实 | 业绩域处理冲正 |
| 业绩归属已计算 | 业绩明细生成 | 分析模块、报表 |
| 业绩汇总已刷新 | 汇总表刷新 | 分析模块 |
