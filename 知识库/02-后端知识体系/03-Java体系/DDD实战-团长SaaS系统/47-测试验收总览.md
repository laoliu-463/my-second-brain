# 测试验收总览

## 概述

每个验收项必须对应脚本、API/SQL 或证据路径。test/mock 证据只能证明本地闭环，不能替代 real-pre。

## 验收原则

- 每个验收项必须对应脚本、SQL/API 或证据路径
- test/mock 证据只能证明本地闭环，不能替代 real-pre
- real-pre 验收必须有真实 Token、真实接口响应和真实环境日志
- 文档重构验收必须证明文件结构、范围标记、归档索引、冲突清单完整

## 脚本入口

| 命令 | 用途 |
| --- | --- |
| `npm run e2e:v1-p0` | V1 P0 浏览器验收 |
| `npm run e2e:real-pre:p0:preflight` | real-pre 预检 |
| `npm run e2e:real-pre:p0` | real-pre P0 联调验收 |
| `npm run test:all` | 前端/E2E 聚合测试入口 |
| `cd backend; mvn test` | 后端单元/集成测试 |
| `cd frontend; npm run build` | 前端构建验证 |

## 证据索引

- P0 映射见 V1-P0 验收清单与 `.claude/qa/P0验收映射.md`
- E2E 映射见 E2E 浏览器测试手册与 `.claude/qa/E2E映射.md`
- real-pre 证据见 real-pre 联调手册与验收证据索引
- 覆盖率口径见 `.claude/qa/覆盖率映射.md`

## 状态分类

| 状态 | 含义 | 是否可收口 |
| --- | --- | --- |
| PASS | 验收通过且证据完整 | 是 |
| PASS_NEEDS_CLEANUP | 主链路通过，但有日志、数据或文档清理项 | 条件通过 |
| BLOCKED | 受外部 Token、权限包、真实样本等阻塞 | 否，需证据 |
| PENDING | 未执行或证据不足 | 否 |
| FAIL | 已复现失败 | 否，需缺陷单 |
