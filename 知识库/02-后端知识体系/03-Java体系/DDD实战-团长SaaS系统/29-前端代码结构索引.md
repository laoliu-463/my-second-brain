# 前端代码结构索引

## 概述

`D:\Projects\SAAS\frontend` 采用 Vue 3 + TypeScript + Vite 技术栈，使用 Naive UI 组件库，Pinia 状态管理，Vue Router 路由管理。目录按视图页面组织。

## 顶层目录结构

| 目录 | 作用 | 说明 |
| --- | --- | --- |
| `src/api/` | API 调用层 | 封装 Axios，统一拦截器和错误处理 |
| `src/assets/` | 静态资源 | 图片、字体等 |
| `src/components/` | 公共组件 | 可复用的 Vue 组件 |
| `src/composables/` | 组合式函数 | Vue 3 Composition API 逻辑复用 |
| `src/config/` | 前端配置 | 环境变量、路由配置等 |
| `src/constants/` | 常量定义 | 业务常量、枚举 |
| `src/router/` | 路由管理 | Vue Router 路由定义与守卫 |
| `src/stores/` | 状态管理 | Pinia Store（用户、商品、寄样等） |
| `src/styles/` | 样式文件 | 全局样式、变量定义 |
| `src/theme/` | 主题配置 | Naive UI 主题定制 |
| `src/types/` | TypeScript 类型 | 接口定义、类型声明 |
| `src/utils/` | 工具函数 | 通用工具方法 |
| `src/views/` | 页面视图 | 按业务模块组织的页面组件 |

## views/ 页面目录

| 视图目录 | 关联领域 | 主要功能 |
| --- | --- | --- |
| `views/dashboard/` | 分析模块 | Dashboard 看板、图表展示 |
| `views/data/` | 分析/数据 | 数据报表、业绩汇总 |
| `views/dev/` | 调试 | 种子数据、测试接口 |
| `views/layout/` | 布局 | 侧边栏、头部、布局组件 |
| `views/ops/` | 运维 | 系统监控、操作日志 |
| `views/orders/` | 订单域 | 订单列表、订单详情、归因 |
| `views/product/` | 商品域 | 商品管理、活动商品、转链 |
| `views/profile/` | 用户 | 个人中心、资料管理 |
| `views/sample/` | 寄样域 | 寄样申请、审批、发货 |
| `views/system/` | 系统 | 用户管理、角色管理、组织管理 |
| `views/talent/` | 达人域 | 达人列表、达人详情、渠道关系 |

## API 层结构

```
src/api/
├── product.ts      # 商品 API
├── sample.ts       # 寄样 API
├── talent.ts       # 达人 API
├── order.ts        # 订单 API
├── user.ts         # 用户 API
├── system.ts       # 系统 API
└── index.ts       # Axios 实例配置
```

## Store 状态管理

Pinia Store 按业务模块组织，主要包含：

| Store | 作用 |
| --- | --- |
| `stores/user.ts` | 用户登录态、权限、Token |
| `stores/product.ts` | 商品列表、筛选条件 |
| `stores/talent.ts` | 达人列表、筛选条件 |
| `stores/sample.ts` | 寄样列表、状态 |
| `stores/order.ts` | 订单列表、订单详情 |
