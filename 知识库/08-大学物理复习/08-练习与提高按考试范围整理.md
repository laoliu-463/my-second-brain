## 考试范围过滤规则

| 范围 | 处理方式 |
|------|------|
| 质点力学 | 期末范围，也是平时模块考试范围；优先整理选择、填空、简单计算、综合计算。 |
| 刚体力学 | 期末范围；重点整理转动惯量、转动定律、角动量与机械能相关题。 |
| 静电场 | 期末范围；本批 PDF 没有可确认的静电场练习册文件，先使用课件题目。 |
| 狭义相对论 | 平时模块考试范围；课程说明明确写明“不参加期末考试”。 |
| 机械振动 | 课程说明明确“不要求”，若练习册中出现应整段排除。 |
