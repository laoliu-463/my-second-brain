# 大学物理题目答案与解题模板

## 概述

本页把课件题、期末模拟卷和《练习与提高》里与考试范围直接相关的题目整理成可刷题使用的答案页。PDF 已用用户提供的打开密码抽取文字；密码不写入知识库正文。原始图像题仍以原 PDF/PPT 图为准，但这里给出可直接核对的答案、公式和关键步骤。

### 计算题 3：变力做功

题目：`F=(5x+4)i`，从 `x=0` 到 `x=10m`。

```text
W=∫0^10(5x+4)dx
 = [2.5x^2+4x]0^10
 = 290 J
```

答案：`290 J`。

### 计算题 4：子弹射入细杆

已知：`M=0.18kg`，`L=1m`，子弹质量 `m=M/9=0.02kg`，入射点 `r=3L/4=0.75m`，`v=10m/s`。

碰撞瞬间绕 O 点角动量守恒：

```text
mvr = (I杆 + mr^2)ω
I杆 = ML^2/3 = 0.06 kg·m^2
mr^2 = 0.01125 kg·m^2
ω = mvr/(I杆+mr^2)
  = 0.02×10×0.75 / 0.07125
  ≈ 2.11 rad/s
```

答案：`ω≈2.11 rad/s`。

### 计算题 5：等边三角形中心电势

等边三角形中心到顶点距离：`a/√3`。

```text
V0 = k(-q+2q+4q)/(a/√3)
   = 5√3 kq/a
K∞ = q0V0 = 5√3 kqq0/a
```

答案：中心电势 `V0=5√3 kq/a`；若 `q0>0` 且从静止释放到无穷远，末动能 `K∞=5√3 kqq0/a`。

### 计算题 6：A、B 与滑轮

图中 A、B 和滑轮质量都为 `m=2kg`，`R=0.1m`，`F=20N`，滑轮为均匀圆盘。

设 A 向右、B 向左、滑轮逆时针方向为正：

```text
F-T1=ma
T2=ma
(T1-T2)R=Iα
I=1/2 mR^2
α=a/R
```

代入得：

```text
T1-T2=(I/R^2)a=(1kg)a
20-T1=2a
T2=2a
a=4 m/s^2
α=40 rad/s^2
T1=12 N
T2=8 N
```

答案：`α=40 rad/s^2`；A 端绳张力 `12N`，B 端绳张力 `8N`。

### 计算题 7：均匀带电球与负电球壳

电荷密度：内球 `+ρ`，外球壳 `-ρ`。用高斯面分区：

```text
0<r<R1:
E = ρr/(3ε0) rhat

R1<r<R2:
E = ρR1^3/(3ε0r^2) rhat

R2<r<R3:
E = ρ(R1^3+R2^3-r^3)/(3ε0r^2) rhat
```

球与球壳之间电势差：

```text
U12 = ∫R1^R2 E dr
    = ρR1^3/(3ε0) (1/R1 - 1/R2)
```

### 计算题 3：平面运动的速度与功

题目：`r=(3t+2t^3)i+0.5t^2j`，`m=2kg`。

```text
v=dr/dt=(3+6t^2)i+t j
v(2)=27i+2j
v(0)=3i
W合=ΔK=1/2 m(|v(2)|^2-|v(0)|^2)
   = 1×(27^2+2^2-3^2)
   = 724 J
```

答案：`v(2)=27i+2j (m/s)`；`W=724J`。

### 计算题 4：子弹射入水平细棒

碰撞瞬间绕 O 点角动量守恒：

```text
mvL = (ML^2/3 + mL^2)ω
ω = mv/[L(m+M/3)]
```

若 `M=9m`：

```text
ω = v/(4L)
K = 1/2(ML^2/3+mL^2)ω^2
  = mv^2/8
```

### 计算题 5：均匀带电细杆延长线电势

`λ=q/L`，P 到近端距离 `a`，Q 到近端距离 `3a`。

```text
VP = k(q/L) ln((L+a)/a)
VQ = k(q/L) ln((L+3a)/(3a))
WPQ = q0(VP-VQ)
    = kqq0/L · ln(3(L+a)/(L+3a))
```

### 计算题 6：斜面滑块与定滑轮

已知：`mA=mB=2kg`，滑轮 `M=4kg`，`R=0.2m`，`I=MR^2/2`，`g=10m/s^2`，`θ=30°`。

设 B 向下、A 沿斜面向上：

```text
mB g - T2 = mB a
T1 - mA g sinθ = mA a
(T2-T1)R = Iα
α=a/R
```

联立：

```text
a = (mB g - mA g sinθ)/(mA+mB+I/R^2)
  = (20-10)/(2+2+2)
  = 5/3 m/s^2
α = a/R = 25/3 rad/s^2
s = 1/2 at^2 = 1/2×(5/3)×9 = 7.5m
```

答案：`a=5/3 m/s^2`，`α=25/3 rad/s^2`，3 秒下降距离 `7.5m`。

### 计算题 7：非均匀带电球

题目给 `ρ(r)=kr`。课程说明里“不要求球对称不均匀分布”，所以这题作为扩展题处理。

```text
Q = ∫0^R 4πr^2 kr dr = πkR^4

r<R:
q内 = ∫0^r 4πr'^2 kr' dr' = πkr^4
E = q内/(4πε0r^2) = kr^2/(4ε0)

r>R:
E = Q/(4πε0r^2) = kR^4/(4ε0r^2)

V(r>R)=∫∞^r E dr = kR^4/(4ε0r)
```

## 不优先刷的题

- 相对论：只用于平时模块考试，期末前时间紧时放后。
- 球对称不均匀带电体：课程说明明确“不要求”，模拟卷 2 第七题作为扩展题即可。
- 机械振动：本课程说明明确不要求。
- 轴对称、镜像对称带电体用高斯定理的特定题：不要求推导，但要会使用已知场强结论叠加。
