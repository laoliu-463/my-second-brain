# 大学物理期末复习讲义与公式表

## 概述

这页是考前直接复习用的“压缩讲义”：只按 2026 春大学物理（A）I 重修课要求整理。期末卷面重点是质点力学、刚体力学、静电场；狭义相对论只用于平时模块考试，不参加期末考试。刷题答案与计算模板见 [[知识库/08-大学物理复习/10-题目答案与解题模板|题目答案与解题模板]]。

## 先记考试范围

| 模块 | 期末优先级 | 复习动作 |
|------|------|------|
| 质点力学 | 最高 | 会列运动方程、会积分求运动、会用牛顿定律、动量、功和能量。 |
| 刚体力学 | 高 | 会算转动惯量、力矩方程、角动量守恒、滑轮约束。 |
| 静电场 | 高 | 会用库仑定律、电场叠加、高斯定理、电势和电场力做功。 |
| 狭义相对论 | 模块考试 | 记公式和典型题；期末不优先。 |
| 机械振动 | 不要求 | 不作为本轮复习重点。 |

明确不要求：

- 相对运动不要求：练习册 P10 填空 4、P11 计算题 3、P14 选择 2。
- 轴对称、镜像对称带电体不要求用高斯定理求解：P50 填空 2，但可以使用已知结论叠加。
- 球对称带电体不要求不均匀分布：P51 计算 2。
- 第三部分机械振动不要求。

## 质点运动学

### 基本量

- 位置矢量：`r(t)=x(t)i+y(t)j+z(t)k`
- 位移：`Δr=r2-r1`
- 速度：`v=dr/dt`
- 加速度：`a=dv/dt=d2r/dt2`
- 路程是轨迹长度，位移是首末位置差；一维往返题最容易把二者混掉。

### 直角坐标求导与积分

已知运动方程：

- `vx=dx/dt`，`vy=dy/dt`
- `ax=dvx/dt`，`ay=dvy/dt`

已知加速度和初始条件：

- `v=v0+∫a dt`
- `r=r0+∫v dt`
- 若加速度给成 `a(x)`，常用 `a=dv/dt=v dv/dx`

典型模板：

```text
1. 先把 x(t)、y(t) 分别求导，得到 vx、vy。
2. 再求导得到 ax、ay。
3. 若题目问速率，用 |v|=sqrt(vx^2+vy^2)。
4. 若问功或动能变化，可先求首末速度，再用 ΔK。
```

### 自然坐标与圆周运动

- 加速度分解：`a=aτ τ + an n`
- 切向加速度：`aτ=dv/dt`
- 法向加速度：`an=v^2/R`
- 角速度：`ω=dθ/dt`
- 角加速度：`α=dω/dt`
- 圆周运动：`v=Rω`，`aτ=Rα`，`an=Rω^2`

常见选择题判断：

- `aτ=0` 且 `an≠0`：匀速圆周运动，速率不变但速度方向变。
- `a` 为常矢量且轨迹不是直线：匀变速曲线运动。
- 变速圆周运动的加速度大小：`a=sqrt((dv/dt)^2+v^4/R^2)`。

## 质点动力学、动量、功和能量

### 牛顿定律

先画受力图，再选坐标轴：

- 直线运动：`ΣFx=max`
- 曲线运动：沿切向、法向分解
- 圆周/摆球：法向方程常写成 `ΣFn=mv^2/R`

摆球例题常用结论：

- 能量：`v^2=v0^2-2gl(1-cosθ)`
- 绳张力：`T=m(v^2/l+g cosθ)=m(v0^2/l-2g+3g cosθ)`

### 动量与冲量

- 冲量：`I=∫F dt`
- 动量定理：`I=Δp=mv2-mv1`
- 系统合外力冲量为零时，动量守恒。

碰撞题判断：

- 完全非弹性碰撞：碰后共同速度，动量守恒，机械能损失最大。
- 弹性碰撞：动量和动能都守恒。
- 子弹打木块、子弹打杆：碰撞瞬间通常用动量或角动量守恒，碰后运动再用能量。

### 功与能量

- 恒力做功：`W=F·Δr`
- 变力做功：`W=∫F·dr`
- 动能定理：`W合=ΔK`
- 保守力：`W保=-ΔU`
- 机械能守恒：只有保守力做功时，`K+U=常量`

常见积分：

- `F=(5x+4)i`，从 `x=0` 到 `10m`：`W=∫0^10(5x+4)dx`
- 阻力与深度成正比：用 `∫F dx=ΔK`
- 已知轨迹 `y=f(x)`：把 `dy` 换成 `f'(x)dx` 后做线积分。

## 刚体定轴转动

### 平动与转动对照

| 平动 | 转动 |
|------|------|
| `m` | `I` |
| `v` | `ω` |
| `a` | `α` |
| `F=ma` | `M=Iα` |
| `K=1/2 mv^2` | `K=1/2 Iω^2` |
| `p=mv` | `L=Iω` |
| `W=∫F dx` | `W=∫M dθ` |

### 常用转动惯量

- 质点：`I=mr^2`
- 均匀圆盘绕中心垂直轴：`I=1/2 mR^2`
- 均匀细棒绕质心垂直轴：`I=1/12 ml^2`
- 均匀细棒绕端点垂直轴：`I=1/3 ml^2`
- 薄圆环绕中心垂直轴：`I=mR^2`
- 平行轴定理：`I=Ic+md^2`

### 滑轮与绳约束

绳不伸长、无相对滑动：

- 两端线加速度大小按绳长约束确定。
- 滑轮角加速度：`α=a/R`
- 两边张力通常不相等，因为滑轮有转动惯量。
- 滑轮力矩方程：`(T2-T1)R=Iα`，符号按选定转向写。

典型解题顺序：

```text
1. 对每个物体列平动方程。
2. 对滑轮列转动方程。
3. 写约束 α=a/R。
4. 联立求 a、α、T1、T2。
```

### 角动量守恒

- 若对某轴合外力矩为零：`L=常量`
- 碰撞瞬间若轴冲量矩不计，常用 `L前=L后`
- 人在转台上跑、收绳、子弹射入细杆，都是高频角动量题。

## 静电场

### 基本公式

令 `k=1/(4πε0)`：

- 库仑力：`F=k q1 q2/r^2`
- 点电荷电场：`E=k q/r^2 rhat`
- 电场叠加：`E=ΣEi` 或 `E=∫dE`
- 电势：`V=Ep/q0`
- 点电荷电势：`V=kq/r`
- 电场力做功：`Wab=q(Va-Vb)`
- 电势差：`Va-Vb=∫a^b E·dl`

### 高斯定理

- 电通量：`Φe=∮E·dS`
- 高斯定理：`∮E·dS=q内/ε0`

能直接用高斯定理的关键是对称性：

- 球对称：场强沿径向，同一球面上大小相等。
- 无限长线：场强沿径向，同轴圆柱面上大小相等。
- 无限大平面：场强垂直平面，两侧大小相等。

本课程说明里，“轴对称、镜像对称带电体不要求应用高斯定理求解”的指定题不要硬钻，但已知结论要会用。

### 高频结论

| 带电体 | 场强 |
|------|------|
| 均匀带电球面，总电量 `Q` | `r<R: E=0`；`r>R: E=kQ/r^2` |
| 均匀带电球体，总电量 `Q` | `r<R: E=kQr/R^3`；`r>R: E=kQ/r^2` |
| 无限长均匀带电直线 | `E=λ/(2πε0 r)` |
| 无限大均匀带电平面 | `E=σ/(2ε0)` |
| 两无限大平行板，面密度 `±σ` | 板间 `E=σ/ε0`，板外近似 0 |

### 常用电势

- 点电荷：`V=kq/r`
- 均匀带电圆环轴线上：`V=kQ/sqrt(R^2+x^2)`
- 均匀带电球面：`r>R: V=kQ/r`；`r<R: V=kQ/R`
- 均匀带电球体：`r>R: V=kQ/r`；`r<R: V=kQ(3R^2-r^2)/(2R^3)`
- 均匀带电细杆延长线上，点到近端距离 `a`：`V=k(q/L)ln((L+a)/a)`

### 导体静电平衡

- 导体内部 `E=0`
- 整个导体等势
- 净电荷只分布在外表面；若空腔内有点电荷，内表面感应等量异号电荷。
- 接地导体球与外部点电荷题：可用镜像法结论，感应总电量常等于等效像电荷。

## 狭义相对论模块

相对论不参加期末，但平时模块考试要看。

### 洛伦兹因子

`γ=1/sqrt(1-v^2/c^2)`

### 运动学效应

- 钟慢：`Δt=γΔt0`
- 尺缩：`l=l0/γ`
- 洛伦兹变换：`x'=γ(x-vt)`，`t'=γ(t-vx/c^2)`
- 同时性的相对性：一个系同时，另一个相对运动系不一定同时。

### 动力学

- 相对论质量：`m=γm0`
- 动量：`p=γm0v`
- 总能量：`E=γm0c^2`
- 静能：`E0=m0c^2`
- 动能：`K=(γ-1)m0c^2`
- 能量动量关系：`E^2=(pc)^2+(m0c^2)^2`

## 题型速查

| 题型 | 第一反应 |
|------|------|
| 运动方程题 | 求导得速度、加速度；积分题先代初始条件。 |
| 圆周运动选择题 | 切向变速看 `dv/dt`，法向变向看 `v^2/R`。 |
| 受力计算题 | 画受力图，分方向列 `ΣF=ma`。 |
| 碰撞题 | 碰撞瞬间先找守恒量，完全非弹性碰后共同速度。 |
| 功和能题 | 变力积分或直接用 `W=ΔK`。 |
| 刚体滑轮题 | 物体平动方程 + 滑轮转动方程 + `α=a/R`。 |
| 子弹打杆题 | 绕轴角动量守恒求碰后 `ω`。 |
| 静电场选择题 | 先看对称性，再看分区，再判方向。 |
| 电势题 | 电势是标量，直接代数叠加；电场是矢量，要分量叠加。 |
| 高斯题 | 只在 `E` 能从积分号里拿出来时最省力。 |
