# 本地全电脑文件检索方案

## 定位

本方案用于让 Codex、Hermes、Claude 等本机代理通过统一的本地 SQLite 索引检索电脑文件。原文和索引默认只保存在本机，不上传 EverOS。

EverOS 的职责仍是记住维护上下文和高价值摘要；本地文件索引负责找文件、给路径、给片段。需要上传时，应由用户明确选择具体摘要或文件片段。

## 工具入口

脚本：

```powershell
python tools/local_file_index.py --help
```

默认索引库：

```text
tmp/local-file-index/files.sqlite3
```

该目录已加入 `.gitignore`，避免把本地索引库提交进仓库。

## 推荐使用方式

先做候选文件统计，不写库：

```powershell
python tools/local_file_index.py scan --preset common --dry-run
```

索引常用目录：

```powershell
python tools/local_file_index.py scan --preset common
```

检索：

```powershell
python tools/local_file_index.py search "EverOS integration" --limit 10
```

查看索引统计：

```powershell
python tools/local_file_index.py stats
```

抽取单个文件文本：

```powershell
python tools/local_file_index.py show "D:\Docs\Books\my second brain\index.md" --extract
```

## 全盘索引

全盘索引需要显式确认：

```powershell
python tools/local_file_index.py scan --preset all-drives --allow-all-drives --dry-run
python tools/local_file_index.py scan --preset all-drives --allow-all-drives
```

默认会跳过系统目录、依赖目录、虚拟环境、Git 目录、缓存目录、`.env`、私钥、证书和 SQLite/数据库文件。

## 默认可索引类型

- 文本与 Markdown：`.txt`、`.md`
- 代码与配置：`.py`、`.js`、`.ts`、`.java`、`.go`、`.rs`、`.json`、`.yaml`、`.toml`、`.sql` 等
- 表格与结构化文本：`.csv`、`.xml`、`.html`
- 文档：`.pdf`、`.docx`、`.pptx`、`.xlsx`

PDF、Word、PPT、Excel 的抽取依赖当前 Python 环境中已存在的 `pypdf`、`python-docx`、`python-pptx`、`openpyxl`；当前环境已检测到这些依赖。

## 安全边界

- 不索引 `.env`、私钥、证书、密码库、SQLite/数据库文件。
- 不自动上传任何文件内容到 EverOS。
- 不把索引库纳入版本控制。
- 不把搜索结果当成最终事实；涉及知识库正式修改仍需打开原文件核验。
- 全盘索引前应先执行 `--dry-run`，确认候选文件数量和扫描范围。

## 与 EverOS 的配合

推荐链路：

```text
本地文件索引 search
  -> Codex 读取命中文件
  -> 用户确认高价值摘要
  -> tools/everos_memory.py add 或 add-file 写入 EverOS
```

这样可以做到“全电脑可检索”和“长期上下文可记忆”分层，不把所有原文都放到云端记忆系统。
