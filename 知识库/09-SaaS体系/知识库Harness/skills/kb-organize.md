# Skill: kb-organize

## 触发条件

孤立文件需要归类时使用。从 `kb-audit` 获取孤立清单。

## 步骤

### 1. 判断孤立原因

| 原因 | 处理方式 |
|---|---|
| 有内容但无索引 | 找到最合适分类，写入该分类 index.md |
| 放错位置（vault 根目录） | 移动到正确分类 |
| 重复内容 | 合并或删除副本 |
| 临时文件 | 收件箱或删除 |

### 2. 分类判断

按 TASK_ROUTING.md 的分类规则判断。

### 3. 移动文件

- 计算相对路径
- 复制到目标分类
- 删除原文件
- 更新目标 index.md

### 4. 验证

- 目标 index.md 能找到新文件
- 原文件不存在
- 无 broken links

## 证据要求

- 原路径 → 新路径清单
- 每个文件移动原因
- 更新的 index.md diff

## 注意事项

- 不确定时优先保留，不移动
- 批量移动需要 manifest
