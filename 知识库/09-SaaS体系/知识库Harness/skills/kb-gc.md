# Skill: kb-gc

## 触发条件

用户说"清理知识库"、"GC"、"复核空文件"、"处理重复文件"时使用。

## 子任务

### KB-GC-STUBS — 复核空文件

0 字节文件和 < 200 字节无意义文件。

**处理**：
- 0 字节：转为兼容入口、复核项或归档候选；未经用户确认不得删除
- stub 但有内容：保留，补标题、索引或迁移计划
- 所有处理写入 `知识库/_review/unresolved-items.md`

### KB-GC-DUP — 清理重复文件

同标题不同路径的文件。

**处理**：
- 保留信息最完整的版本
- 其他版本转为重定向、归档候选或复核项
- 记录重复关系、主页面和回滚方式

### KB-GC-INBOX — 清理收件箱

00-收件箱/ 和 00-收集箱/ 下文件。

**处理**：
- 有价值 → 归入对应分类
- 临时文件 → 写入复核清单，未经确认不得删除
- 无法判断 → 记录到待办清单

### KB-GC-RAW — 清理原始资料

raw/sources/ 下未整理文件。

**处理**：
- 视频转写 → 提取主题 → 归入对应分类
- PDF 笔记 → 归入知识库 → raw/ 保留原文件
- 过期内容 → 写入归档候选；已有归档规则时才移动，不自动删除

## 禁止事项

- 不自动删除文件
- 不覆盖 raw 原文
- 不删除认知成长类文件
- 任何删除都必须由用户明确确认，并提前给出路径、原因、替代位置和回滚方式
