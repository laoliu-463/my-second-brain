# Skill: kb-gc

## 触发条件

用户说"清理知识库"、"GC"、"删除空文件"时使用。

## 子任务

### KB-GC-STUBS — 清理空文件

0 字节文件和 < 200 字节无意义文件。

**处理**：
- 0 字节：直接删除（立即执行）
- stub 但有内容：保留，移入对应分类

### KB-GC-DUP — 清理重复文件

同标题不同路径的文件。

**处理**：
- 保留信息最完整的版本
- 其他版本移动到 `知识库/90-来源与映射/` 或删除
- 记录删除清单

### KB-GC-INBOX — 清理收件箱

00-收件箱/ 和 00-收集箱/ 下文件。

**处理**：
- 有价值 → 归入对应分类
- 临时文件 → 删除
- 无法判断 → 记录到待办清单

### KB-GC-RAW — 清理原始资料

raw/sources/ 下未整理文件。

**处理**：
- 视频转写 → 提取主题 → 归入对应分类
- PDF 笔记 → 归入知识库 → raw/ 保留原文件
- 过期内容 → 删除

## 禁止事项

- 不删除有内容的文件
- 不删除认知成长类文件
- 删除前必须检查内容
