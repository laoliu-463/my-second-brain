# Knowledge Base Session Exit Gate

每次知识库整理会话结束前，必须满足：

## 1. 文件修改已记录

- 新建/移动/删除的文件已记录在会话摘要中
- 受影响的 index.md 已更新

## 2. 临时文件已清理

- 0 字节文件当场删除，不留到下次
- "未命名"文件已决策（归档或删除）
- 收件箱文件已处理或已标注延期原因

## 3. 未整理文件有归属

- raw/sources/ 下新增文件已标注状态
- 孤立文件已列入 KB-GC 待办清单

## 4. 状态文件已更新

- `state/KB_STATUS.md` 当前状态已更新
- `state/KB_TASK_MATRIX.md` 待办项已刷新

## 5. 下次会话交接清晰

- 在 `state/KB_TASK_MATRIX.md` 写明下次优先任务
- 不留下无法理解的历史遗留问题
