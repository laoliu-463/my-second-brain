# Knowledge Base Forbidden Scope

## 绝对禁止

1. **删除有知识价值的文件**（哪怕暂时读不懂）
2. **创建与现有重复的文件**（先 rg 搜索）
3. **将密钥、凭证、密码写入 md 文件**
4. **修改 .obsidian/ 配置**（Obsidian 工作区配置）
5. **修改 .git/ 内容**（版本控制）

## 高风险操作（需二次确认）

1. 删除 > 5 个文件（需 manifest）
2. 移动整个分类目录
3. 修改 index.md 的链接结构
4. 删除 0 字节以外的 stub（需确认内容确实无用）

## 保护路径

以下路径下文件受保护，删除前必须确认：
- `知识库/05-认知与成长/` — 个人认知记录
- `知识库/07-面试备战/` — 求职资料
- `知识库/03-地缘政治/` — 研究资料
