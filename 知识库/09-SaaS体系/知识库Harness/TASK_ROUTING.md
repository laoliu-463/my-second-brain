# Knowledge Base Task Routing

## 任务类型总览

| 任务类型 | 触发关键词 | 入口 Skill |
|---|---|---|
| 日常巡检 | "巡检知识库"、"LINT" | `kb-audit.md` |
| 整理归类 | "整理"、"归档"、"迁移"、"沉淀"、"来源页" | `kb-organize.md` |
| 垃圾回收 | "GC"、"清理孤立"、"复核空文件" | `kb-gc.md` |
| 新建内容 | "新建笔记"、"创建条目" | 判断分类 → 对应目录下创建 |
| 全面审计 | "全面审计"、"harness 知识库" | `kb-audit.md` + `kb-gc.md` |

### 0. 路由前置（强制）

- 先确认输入类型（新资料、修订、修复、巡检）
- 再确认影响范围（单文件、批量、状态链）
- 再确认依赖链完整性（是否依赖已有任务、决策、索引）
- 依赖链未闭合时先补齐证据，禁止直接修改

## 路由规则

### 1. 新文件进入规则

新建文件时，按以下优先级判断分类：

```
LLM Wiki/     → 系统级入口（项目索引、入口文档）
知识库/09-SaaS体系/  → SaaS 项目相关（Harness、DDD、技术体系）
知识库/02-后端知识体系/ → 后端技术知识（Java、JS、网络、数据库等）
知识库/05-认知与成长/  → 认知成长、学习记录
知识库/06-内容创作与传播/ → 内容相关
知识库/07-面试备战/  → 求职面试
知识库/03-地缘政治/  → 地缘政治研究
知识库/04-方法论与工具/ → 方法论、工具使用
知识库/08-大学物理复习/ → 大学物理复习资料
raw/sources/  → 原始资料（未整理）
```

### 2. 孤立文件处理

文件无 index 引用时，判断顺序：
1. 有内容但无索引 → 归入对应分类
2. 重复内容 → 记录重复关系，副本转重定向/归档候选/复核项
3. 临时文件 → 写入复核清单，未经确认不得删除
4. 0 字节文件 → 转兼容入口或复核项，未经确认不得删除

### 3. raw/sources/ 处理

raw/ 目录下文件是原始资料，处理规则：
- 视频转写 → 整理到对应主题分类（如认知成长、内容创作）
- PDF/文档 → 提取要点到知识库，原文件保留在 raw/
- 过期资料 → 记录为归档候选；已有归档规则时才移动，不自动删除

### 4. GC 任务路由

| 症状 | Action |
|---|---|
| 孤立文件 > 50 | KB-GC-ORPHANS：批量归类 |
| 0 字节文件存在 | KB-GC-STUBS：转兼容入口或复核项 |
| 收件箱超 3 天 | KB-GC-INBOX：当天必须清空 |
| raw/sources/ 超 30 未整理 | KB-GC-RAW：批量处理 |
| 重复标题文件 | KB-GC-DUP：合并主页面，副本转重定向或复核项 |

### 5. 路由与依赖链映射（工程约束）

| 触发类型 | 依赖链主干 | 关键验收 |
|---|---|---|
| 资料吸收 | raw/sources → Ingest → index → KB_STATUS |
| 资料吸收 | 任务模板 → 路由表 → 任务队列 |
| 归类整理 | 索引更新 → 状态文件更新 → 任务队列闭环 |
| GC 清理 | LINT 结果 → manifest/archive → 复核或归档记录 |

## 完成门禁

所有知识库任务必须选择以下 Gate 之一并输出证据：

- **Gate 0**：扫描完成，列出待处理清单（不修改文件）
- **Gate 1**：修改完成，修改文件列表 + 修改原因
- **Gate 2**：归档/复核完成，路径映射 + 原因 + 回滚记录
- **Gate 3**：新建完成，新建文件 + 归属分类 + index 更新
