# Agent Skills

## 概述

Agent Skills 是把某类任务的专业知识、流程约束、工具用法和可复用资源封装成可触发的技能包。模型负责理解和规划，Skill 负责把任务落到稳定步骤、输入输出和验证规则上。（来源：[[知识库/sources/src-20260617-runoob-skills-tutorial|菜鸟教程 Skills 来源]]；原文：[[raw/sources/src-20260617-runoob-skills-tutorial/original.md|Skills 教程原文]]）

## 稳定表述

- Skills 不是业务判断本身，而是让 Agent 在特定任务中遵循既定流程和边界。（来源：[[知识库/sources/src-20260617-runoob-skills-tutorial|菜鸟教程 Skills 来源]]；原文：[[raw/sources/src-20260617-runoob-skills-tutorial/original.md|Skills 教程原文]]）
- 好的 Skill 通常包含触发条件、操作步骤、验证方式和必要资源，避免每次重新解释上下文。（来源：[[知识库/05-智能体与Agent体系/mattpocock-skills研究|mattpocock/skills 研究]]；原文：[README](https://raw.githubusercontent.com/mattpocock/skills/main/README.md)）
- 对工程任务来说，Skill 的价值不是“让代码看起来完整”，而是把复现、证据、最小修改和验证门禁固定下来。（来源：[[知识库/05-智能体与Agent体系/mattpocock-skills研究|mattpocock/skills 研究]]；原文：[GitHub repository](https://github.com/mattpocock/skills)）
