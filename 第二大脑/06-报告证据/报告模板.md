# 报告模板.md

> 新建报告时复制此文件内容到 `报告-XXX.md`，填实际内容。

```text
# <报告标题>

> 简短描述，1-2 句。

## 1. 背景

为什么有这个报告？哪个任务/事件触发？

## 2. 范围

- 涉及文件：
- 涉及目录：
- 涉及任务：
- 时间范围：

## 3. 结论

- 关键发现 1
- 关键发现 2
- 关键发现 3

## 4. 证据

- 路径 / 命令 / 输出

## 5. 风险

- 风险 1
- 缓解 1

## 6. 后续

- 动作 1
- 动作 2
```

## 字段说明

- **背景**：必填
- **范围**：必填，列具体文件
- **结论**：DONE 时必填
- **证据**：必填（路径 / 命令 / 输出）
- **风险**：可空
- **后续**：可空

## 类型

- 治理报告（GC、限制校验）
- 状态报告（业务、技术债）
- 审计报告（订单、业绩、权限）
- 知识库报告（对齐、合并）
