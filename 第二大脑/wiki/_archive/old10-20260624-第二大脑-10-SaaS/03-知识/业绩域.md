# 业绩域.md

> V1 业绩域业务合同。

## 领域职责

- 最终归属
- 提成、冲正
- 双轨金额
- 汇总刷新
- 业绩事件

## 领域不负责

- 订单事实采集
- 同步抖音订单
- 修改订单原始事实

## V1 规则

| 规则 | 说明 |
|---|---|
| 输入 | 订单事实 + 达人关系 + 配置参数 |
| 输出 | performance_records |
| 幂等键 | 订单 ID + 版本 |
| 冲正 | 退款后扣减 |
| 事件 | 业绩归属已计算、汇总已刷新 |

## 关键字段

- settle_amount（结算）
- est_amount（预估）
- final_owner（最终归属）
- commission（提成）
- reversal（冲正）

## 验证方式

- 配置变更后汇总一致
- 退款冲正确认
