## 2. 占位文件统一模式

每个实例 27 占位 = 9 + 6 + 4 + 3 + 3 + 2 = 27：

- 5-任务/ 9：任务-001~006 + 任务总表 + 任务模板 + 任务队列
- 6-报告/ 6：报告-001~004 + 报告索引 + 报告模板
- 4-流程/ 4：资料吸收/查询回答/健康检查/任务生命周期
- 根级 3：AGENTS.md + README.md + 日志.md
- 0-规范/ 3：结构规范/页面规范/安全边界
- 8-模板/ 2：页面模板/资料来源模板

## 3. 整理方案（统一模板填 30-80 行）

为每个占位生成 30-80 行的"中等内容"。分类模板：

### 3.1 规范类（3 文件/实例）

- `结构规范.md`：硬约束来源（50/200 索引 + 校验脚本）
- `页面规范.md`：页面格式（标题/概述/小节/关联）
- `安全边界.md`：禁止操作范围

### 3.2 流程类（4 文件/实例）

- `资料吸收流程.md`：新资料如何进入本实例
- `查询回答流程.md`：如何基于本实例回答
- `健康检查流程.md`：LINT 巡检
- `任务生命周期.md`：NEW → WIP → REVIEW → DONE

### 3.3 任务类（9 文件/实例）

- `任务总表.md`：本实例所有任务索引
- `任务队列.md`：当前活跃任务
- `任务模板.md`：任务书写模板
- `任务-001`~`任务-006.md`：6 个动态任务槽位（占位 + 状态）

### 3.4 报告类（6 文件/实例）

- `报告索引.md`：本实例所有报告索引
- `报告模板.md`：报告书写模板
- `报告-001`~`报告-004.md`：4 个动态报告槽位

### 3.5 模板类（2 文件/实例）

- `页面模板.md`：页面模板
- `资料来源模板.md`：源记录模板

### 3.6 根级（3 文件/实例）

- `AGENTS.md`：本实例 Agent 行为合同
- `README.md`：本实例说明
- `日志.md`：本实例操作日志

## 4. 整理执行

- 9 实例 × 27 占位 = 243 文件批量填
- 每文件 30-80 行
- 完成后 10/10 实例 50/200 硬约束 PASS
- 引用 wiki link 全部有效
