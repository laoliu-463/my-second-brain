# 变现模型.md

> 内容变现模型。

## 1. 主要模式

| 模式 | 平台 / 工具 | 收入类型 |
|---|---|---|
| 广告分成 | 公众号 / YouTube / B 站 | 流量分成 |
| 软广 / 植入 | 抖音 / 小红书 / B 站 | 广告费 |
| 知识付费 | 知识星球 / 课程平台 | 课程 / 社群 |
| 直播打赏 | 抖音 / B 站 | 礼物分成 |
| 直播带货 | 抖音 / 快手 | 佣金 + 坑位费 |
| 私域转化 | 微信 / 企微 | 复购 + 高客单 |
| 会员订阅 | 公众号 / 知识星球 | 会员费 |
| 出版 / IP | 出版社 / 影视 | 版权 + 分成 |

## 2. 飞轮模型

```text
内容 → 关注 → 私域 → 复购 → 新内容
  ↑                            ↓
  └──────── 反馈 ←──────── 数据 ←┘
```

## 3. 关键指标

- 关注成本（CAC）
- 内容曝光（impressions）
- 互动率（engagement rate）
- 转化率（CVR）
- 客单价（AOV）
- LTV（生命周期价值）
- 复购率

## 4. 常见陷阱

- ❌ 只做流量不做变现
- ❌ 只接广告不做产品
- ❌ 重金投放不重内容
- ❌ 私域运营疲软

## 5. 平台抽成

| 平台 | 抽成 |
|---|---|
| 抖音直播 | 5-10% |
| 抖音带货 | 1-5% |
| YouTube | 45% 给创作者 |
| B 站 | 50% 给 UP 主 |
| 公众号 | 0%（流量主 50%）|
| 知识星球 | 5% 平台费 |
