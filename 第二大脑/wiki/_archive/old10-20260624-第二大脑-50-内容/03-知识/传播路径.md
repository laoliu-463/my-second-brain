# 传播路径.md

> 内容传播路径与平台策略。

## 1. 平台分布

| 平台 | 调性 | 时长 | 流量逻辑 |
|---|---|---|---|
| 公众号 | 深度 | 长文 | 关注 + 推荐 |
| 微博 | 即时 | 短文 | 热搜 + 大V转发 |
| 知乎 | 深度 | 中长 | 算法 + 关注 |
| 抖音 / TikTok | 视频 | 15-60s | 算法 + 完播率 |
| B 站 | 视频 | 5-30min | 算法 + 互动 |
| 小红书 | 种草 | 图文 | 标签 + 搜索 |
| YouTube | 视频 | 5-20min | 搜索 + 推荐 |
| 视频号 | 视频 | 1-3min | 社交推荐 |

## 2. 流量逻辑

- **算法推荐**：完播率 / 互动率 / 关注率 / 转发率
- **社交推荐**：朋友点赞 / 转发
- **搜索**：SEO + 关键词
- **关注**：私域流量

## 3. 跨平台策略

- 一鱼多吃：核心内容 + 平台变体
- 互导流量：抖音 → 公众号 / 微信群
- 长期阵地：公众号 / 知识星球
- 短期爆发：抖音 / 微博

## 4. 增长黑客

- 钩子设计：前 3 秒决定生死
- 互动引导：评论 / 点赞 / 转发
- 投放：信息流 + KOL
- 数据驱动：A/B 测试

## 5. 平台规则红线

- ❌ 标题党（标题与内容不符）
- ❌ 搬运（原创度）
- ❌ 诱导分享（分享得奖）
- ❌ 涉黄涉政
- ❌ 侵犯版权
