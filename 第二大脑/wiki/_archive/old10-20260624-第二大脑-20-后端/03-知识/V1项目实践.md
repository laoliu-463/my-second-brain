# V1项目实践.md

> V1 项目实际使用的后端实践。

## 1. 技术栈（V1 实际）

| 维度 | 选型 |
|---|---|
| 语言 | Java 17 |
| 框架 | Spring Boot 3.2 + Spring Cloud Gateway |
| ORM | JPA + Hibernate |
| DB | PostgreSQL 13+ |
| 缓存 | Redis 7+ |
| 鉴权 | Spring Security + JWT |
| 测试 | JUnit 5 + Mockito + AssertJ |
| 构建 | Maven |
| 容器 | Docker + docker-compose |

## 2. 项目结构

```text
backend/
├── src/main/java/com/saas/
│   ├── controller/      REST 接口
│   ├── service/         业务逻辑
│   ├── repository/      数据访问
│   ├── domain/          实体 + 领域
│   ├── dto/             数据传输
│   ├── config/          配置
│   ├── exception/       异常
│   └── security/        鉴权
├── src/main/resources/
│   ├── application.yml
│   ├── application-test.yml
│   └── application-real-pre.yml
├── src/test/java/       单元测试
├── pom.xml
└── Dockerfile
```

## 3. 关键设计决策

- **模块化单体**：单仓单进程，按模块分包
- **DDD 渐进式**：领域分层 + 限界上下文
- **接口分离**：Controller → Service → Repository
- **DTO 转换**：禁止 Entity 直接到接口
- **统一异常**：@ControllerAdvice + businessCode
- **API 响应**：`{code, message, data, timestamp}`

## 4. 关键领域

| 域 | 业务 |
|---|---|
| 订单域 | 抖音订单同步 |
| 业绩域 | 服务费、提成 |
| 商品域 | 商品库、转链 |
| 达人域 | 达人认领 |
| 寄样域 | 寄样申请 |
| 用户配置 | 用户、角色 |
| 看板分析 | Dashboard |

## 5. 部署

- test：localhost:8080
- real-pre：localhost:8081 / 远端 1.14.108.159
- 不部署 production
