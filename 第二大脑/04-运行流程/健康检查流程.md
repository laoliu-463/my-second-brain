# 健康检查流程.md

> LINT（巡检）和会话退出检查。每周 / 每次会话结束前必跑。

## 1. 触发条件

- 用户说"LINT"、"巡检"、"健康检查"
- 每次会话结束前
- 修改 `第二大脑/` 下任何文件后

## 2. LINT 步骤

### Step 1：结构约束

```bash
python 第二大脑/07-脚本/line_guard.py
```

检查项：
- 一级子目录 ≤ 10

### Step 2：索引覆盖

```bash
python 第二大脑/07-脚本/brain_lint.py
```

检查项：
- 所有 .md 在 `索引.md` 中被引用
- `索引.md` 引用都对应实际文件
- 无 broken link

### Step 3：关键词搜索可用

```bash
python 第二大脑/07-脚本/brain_search.py "测试关键词"
```

- 能返回 ≥ 1 个结果
- 中文 / 英文都能匹配

### Step 4：人工检查

- 看 `日志.md` 最近 1 周是否有可读动作
- 看 `01-状态/当前状态.md` 是否反映最新
- 看 `01-状态/待确认问题.md` 是否堆积
- 看 `01-状态/技术债台账.md` 是否更新

## 3. 退出会话检查

每次会话结束前必须满足：

### 3.1 文件修改已记录

- 新建/移动/删除的文件已记录在 `日志.md`
- 受影响的 `索引.md` 已更新

### 3.2 临时文件已清理

- 0 字节文件当场删除
- "未命名"文件已决策
- 收件箱文件已处理

### 3.3 未整理文件有归属

- `raw/` / 临时文件夹下新增文件已标注状态
- 孤立文件已列入 GC 待办

### 3.4 状态文件已更新

- `01-状态/当前状态.md` 当前状态已更新
- `01-状态/待确认问题.md` 待办已刷新

### 3.5 下次会话交接清晰

- 在 `05-任务管理/任务队列.md` 写明下次优先任务
- 不留下无法理解的历史遗留问题

## 4. 异常处理

| 异常 | 处置 |
|---|---|
| 索引覆盖不足 | 补 `索引.md` |
| 收件箱 > 3 天 | 立即清空 |
| 临时文件残留 | 删除 |
