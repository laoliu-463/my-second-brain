# 任务生命周期.md

> 任务从 NEW 到 DONE 的规则。所有任务都进 `05-任务管理/`。

## 1. 状态机

```
NEW → WIP → REVIEW → DONE
                ↓
              BLOCKED → WIP → REVIEW → DONE
                
DONE 后可 ACCEPTED（用户接受风险）
任意状态可 CANCELLED
```

| 状态 | 含义 | 转换 |
|---|---|---|
| `NEW` | 任务已建，未开始 | → WIP |
| `WIP` | 工作中 | → REVIEW / BLOCKED |
| `REVIEW` | 等待验证 | → DONE / WIP（验证失败）|
| `BLOCKED` | 阻塞 | → WIP（解除后）|
| `DONE` | 完成 + 证据齐 | → ACCEPTED |
| `ACCEPTED` | 用户接受 | 终态 |
| `CANCELLED` | 取消 | 终态 |

## 2. 步骤

### Step 1：建任务

新建 `05-任务管理/任务-XXX.md`，使用 `任务模板.md`：

```text
# 任务标题
## 任务 ID：任务-XXX
## 状态：NEW
## 触发：...
## 步骤：...
## 验证：...
## 证据：...
## 风险：...
```

### Step 2：登记到队列

`05-任务管理/任务队列.md` 追加任务 ID + 标题 + 状态。

### Step 3：执行

- 切换状态 NEW → WIP
- 按步骤执行
- 中途遇阻塞 → 切 BLOCKED + 写阻塞源

### Step 4：验证

- 切换状态 WIP → REVIEW
- 按"验证"项执行
- 失败 → 切回 WIP

### Step 5：完成

- 切换状态 REVIEW → DONE
- 写证据（路径或命令输出）
- 同步到 `01-状态/当前状态.md`（如影响主线状态）
- 同步到 `01-状态/技术债台账.md`（如修复债务）
- 同步到 `01-状态/已确认决策.md`（如产生新决策）

### Step 6：归档

- 任务完成后，可保留 7 天
- 超过 7 天 → 移动到归档目录（如有）
- 槽位用完 → 复用最旧的槽位

## 3. 6 个动态槽位

`任务-001` ~ `任务-006` 是固定槽位。命名规则：

- `任务-001` 最优先 / 进行中
- `任务-006` 即将归档
- 槽位用完时，复用最旧的（最久没动的）并标 `[RECYCLED]`

## 4. 异常处理

| 异常 | 处置 |
|---|---|
| 任务跨多域 | 拆为多任务 |
| 任务 > 200 行 | 拆分任务；或只放摘要 + 详细归源 |
| 阻塞 > 7 天 | 升级到 `01-状态/待确认问题.md` |
| 同一任务反复 WIP | 反思步骤设计 / 拆任务 |
