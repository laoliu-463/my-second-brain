# 查询回答流程.md

> 如何基于第二大脑回答问题（自己的问题 / Agent 的问题）。

## 1. 触发条件

- 用户说"查一下"、"找一下"、"X 是什么"、"X 怎么做的"
- Agent 在第二大脑覆盖范围内回答问题

## 2. 步骤

### Step 1：定位入口

根据问题类型找最相关目录：

| 问题类型 | 入口 |
|---|---|
| "现在项目状态" | `01-状态/当前状态.md` |
| "X 决策是什么" | `01-状态/已确认决策.md` |
| "X 债务" | `01-状态/技术债台账.md` |
| "X 域边界" | `03-领域知识/<域>.md` |
| "三链怎么走" | `02-项目总览/业务闭环.md` |
| "环境怎么配" | `02-项目总览/环境说明.md` |
| "X 验收" | `02-项目总览/验收门禁.md` |
| "X 任务" | `05-任务管理/任务队列.md` |
| "X 报告" | `06-报告证据/报告索引.md` |

### Step 2：读对应文件

- 单文件 ≤ 200 行
- 读完应能给出 1-3 句直接答案
- 如文件未覆盖，明确告知

### Step 3：必要时跳源

如果第二大脑的页面是摘要，需要详细时：

- 跳 `01-状态/资料来源.md` 找源路径
- 跳到 `D:\Projects\SAAS\harness\` / `docs/` / vault 其他位置
- 不要复制源原文进第二大脑

### Step 4：使用搜索

如果不确定文件位置：

```bash
python 第二大脑/07-脚本/brain_search.py "关键词"
```

支持中英文，回显路径 + 摘要。

### Step 5：回答

回答结构：

1. **直接答案**（1-3 句）
2. **依据**（哪份文件 / 哪个源）
3. **上下文**（必要时给 1-2 句背景）
4. **未覆盖部分**（如有）

## 3. 异常处理

| 异常 | 处置 |
|---|---|
| 第二大脑未覆盖 | 明确告知，建议建新页 |
| 信息冲突 | 列出冲突源，标 `未决` |
| 信息过期 | 标 `[STALE]` + 跳到最新版 |
| 用户要的是第二大脑外的资料 | 提示 vault 其他位置 / 项目侧 |

## 4. 完成标志

- 给出 1-3 句直接答案
- 标出依据（哪份第二大脑文件）
- 必要时跳源
- 未覆盖部分明确告知
