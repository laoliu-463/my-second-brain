# 商品域.md

> V1 商品域业务合同。详细：`D:\Projects\SAAS\docs\领域\商品域.md` + `知识库/09-SaaS体系/Harness-Domains/product-domain.md`。

## 领域职责

- 商品库管理
- 活动商品同步
- 商品展示输入
- 转链
- `pick_source_mapping` 落库
- 为订单归因提供映射事实
- 商品同步、商品库查询、活动商品审核、转链证据

## 领域不负责

- ❌ 订单最终归属
- ❌ 提成 / 冲正
- ❌ 分析看板重算业绩
- ❌ 直接写寄样表

## V1 规则

- 转链成功后必须落 `pick_source_mapping`
- 活动商品以**上游推广中状态**为自动入库主判断
- 历史状态断链必须通过商品域 repair 入口修复
- 禁止裸 SQL 批量直改
- 活动列表点击商品与商品列表活动筛选 URL 必须一致

## 禁止越界

- 禁止商品域计算提成或最终归属
- 禁止商品域绕过寄样域直接创建或改写寄样状态
- 禁止前端绕过商品域审核补充信息

## 关键字段

| 字段 | 含义 |
|---|---|
| `selected_to_library` | 活动商品入库商品库 |
| `audit_status` | 商品库审核状态 |
| `display_status` | 商品库展示状态 |
| `manual_disabled` | 商品库人工禁用 |
