# 订单域.md

> V1 订单域业务合同。详细：`D:\Projects\SAAS\docs\领域\订单域.md` + `知识库/09-SaaS体系/Harness-Domains/order-domain.md`。

## 领域职责

- 抖音订单同步、订单事实保存、订单明细
- 退款 / 售后事实保存
- 同步日志
- 保存 `raw_payload`、双轨金额输入、`pick_source`、`colonel_buyin_id`、默认归因输入
- 发布订单已同步、退款事实已同步事件

## 领域不负责

- ❌ 提成计算
- ❌ 业绩计算
- ❌ 最终归属
- ❌ 独家覆盖
- ❌ 寄样完成
- ❌ 看板汇总
- ❌ 写 `performance_records`

## V1 规则

- 订单域只存事实，不算提成
- 订单同步必须有：幂等键、时间窗口、同步日志、错误证据
- 订单同步后通过事件通知寄样域、业绩域、分析域
- 真实订单才能证明渠道归因闭环

## 禁止越界

- 禁止订单域计算提成 / 最终归属
- 禁止订单域直接更新寄样状态
- 禁止订单域应用独家达人 / 商家 / 个别品负责人覆盖

## 关键字段

| 字段 | 用途 | 风险 |
|---|---|---|
| `pick_source` | 渠道归因来源 | 大量为空 → 真实闭环阻塞 |
| `colonel_buyin_id` | NATIVE 归因键 | 需单独取证 |
| `default_channel_id` | 默认渠道归属 | 必须非空 |
| `default_recruiter_id` | 默认招商归属 | 必须非空 |

- 入口 SQL：`orders` / `pick_source_mapping` / `order_sync_log`
