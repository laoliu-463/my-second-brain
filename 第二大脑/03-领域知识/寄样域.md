# 寄样域.md

> V1 寄样域业务合同。详细：`D:\Projects\SAAS\docs\领域\寄样域.md` + `知识库/09-SaaS体系/Harness-Domains/sample-domain.md`。

## 领域职责

- 寄样申请
- 审核
- 发货
- 物流信息
- 签收
- 待交作业 / 交作业完成
- 状态机
- **基于订单已同步事件**判断交作业完成

## 领域不负责

- ❌ 订单事实同步
- ❌ 业绩归属 / 提成 / 冲正
- ❌ 用物流 API 阻塞寄样主流程

## V1 规则

- 状态变更必须有：操作者、时间、前后状态
- 交作业完成必须基于**订单已同步事件** + 可追溯匹配条件
- real-pre 缺真实归因订单时只能写 BLOCKED / PENDING
- 30 天自动关闭：**V1 不做**
- 物流 API 自动跟踪：**V1 不做**

## 状态机

```
申请 → 审核 → 发货 → 签收 → 待交作业 → 已完成
                          ↓
                       已拒绝
```

## 关键匹配条件

交作业完成的订单匹配键：

```
channel_id + talent_id + product_id + pay_time
```

四个键必须全部命中，缺一即未完成。

## 禁止越界

- 禁止寄样域直接同步抖音订单
- 禁止寄样域计算业绩或提成
- 禁止寄样域绕过状态机直接覆盖最终状态
- 禁止用物流 API 阻塞主流程

## 验证方式

- 探针：`probes/sample-auto-complete.evals.md`
- 入口 SQL：`sample_requests` / 订单事件日志
- 评估：`evals/sample-auto-complete.md`
