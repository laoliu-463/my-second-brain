# 达人域.md

> V1 达人域业务合同。详细：`D:\Projects\SAAS\docs\领域\达人域.md` + `知识库/09-SaaS体系/Harness-Domains/talent-domain.md`。

## 领域职责

- 达人资料
- 标签
- 地址
- 跟进记录
- 认领 / 保护期
- 向寄样、商品、业绩链路提供达人事实

## 领域不负责

- ❌ 订单事实采集
- ❌ 订单归属计算
- ❌ 提成 / 冲正 / 双轨金额
- ❌ 替代订单域或业绩域做最终归属

## V1 规则

- 达人信息必须可支撑寄样、跟进、渠道协作、业绩归属输入
- 第三方达人接口必须提供真实响应或 BLOCKED 证据
- `gender` 筛选缺口按 `docs/领域/达人域.md` 记录处理，不得静默假筛选
- 6 角色 + 4 部门（用户域）

## 禁止越界

- 禁止达人域采集订单事实
- 禁止达人域计算最终归属 / 提成 / 冲正
- 禁止达人域伪造第三方接口数据

## 关键能力

- 列表 / 详情 / 标签 / 地址 / 跟进 API
- 权限数据范围和越权负例
- 第三方接口真实响应或 BLOCKED 证据

## 验证方式

- 探针：`probes/v1-business-closure.evals.md`
- 入口 SQL：`talents` / `talent_tags` / `talent_addresses` / `talent_followups`
- 评估：`evals/v1-business-closure.md`
