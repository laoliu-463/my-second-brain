# 抖音上游接口.md

> V1 与抖音/抖店开放平台的对接规范、字段、真实返回。
> 详细：`D:\Projects\SAAS\docs\08-第三方对接总览.md` + `docs/对接/`。

## 对接范围

V1 涉及的主要抖音上游接口：

| 接口 | 用途 | 域 |
|---|---|---|
| 订单同步 | 拉取订单事实 | 订单域 |
| 商品同步 | 拉取活动商品 / 普通商品 | 商品域 |
| 达人接口 | 拉取达人资料 | 达人域 |
| 转链接口 | 生成带 `pick_source` 的链接 | 商品域 |
| 结算接口 | 拉取结算金额 | 业绩域 |

## 必保开关

```text
APP_TEST_ENABLED=false
DOUYIN_TEST_ENABLED=false
DOUYIN_REAL_UPSTREAM_MODE=live
```

## 关键字段

### 订单接口

| 字段 | 用途 |
|---|---|
| `order_id` | 订单 ID |
| `pick_source` | 渠道归因来源（系统转链/达人分享）|
| `colonel_buyin_id` | NATIVE 归因映射键 |
| `default_channel_id` | 默认渠道归属（系统填充）|
| `default_recruiter_id` | 默认招商归属（系统填充）|
| `settle_amount` | 结算金额 |
| `pay_time` | 支付时间 |

### 商品接口

| 字段 | 用途 |
|---|---|
| `product_id` | 商品 ID |
| `status` | 上游状态（`1` = 推广中）|
| `selected_to_library` | 是否入库商品库 |

### 达人接口

| 字段 | 用途 |
|---|---|
| `talent_id` | 达人 ID |
| `gender` | 性别 |
| `tags` | 标签 |
| `addresses` | 地址列表 |

## 真实样本要求

- real-pre 必须有真实响应或 BLOCKED 证据
- mock 数据只能用于 test
- 接口缺权限 / 缺 Token / 缺真实样本 → 阻塞证据保留
