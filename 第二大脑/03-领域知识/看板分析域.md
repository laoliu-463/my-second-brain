# 看板分析域.md

> V1 分析模块业务合同。详细：`D:\Projects\SAAS\docs\领域\分析模块.md` + `知识库/09-SaaS体系/Harness-Domains/analytics-module.md`。

## 领域职责

- Dashboard
- 报表
- 趋势 / 排行
- 对账
- 导出
- 只读汇总展示
- 按用户域数据范围读取业绩和订单汇总

## 领域不负责

- ❌ 订单同步 / 归因 / 提成 / 冲正
- ❌ 修改订单 / 寄样 / 业绩 / 配置事实
- ❌ 重新扫描订单产生新最终归属
- ❌ 高级 BI 和整体数据平台导出

## V1 规则

- 分析模块只读汇总表 / 报表快照 / 事实查询
- dashboard 指标必须能通过 API / SQL 对账
- **不得重新扫描订单**产生新的最终归属
- 看板以真实汇总和已落库事实为准
- 复杂 BI 分析能力不作为 V1 必需

## 禁止越界

- 禁止分析模块重新计算业绩归因
- 禁止分析模块写回订单 / 寄样 / 业绩结论
- 禁止将展示口径反向固化为业务规则
- 禁止直接穿透业务域 Repository 做写操作

## 关键双轨

- `est_amount`（预估）：用于实时看板
- `settle_amount`（结算）：用于最终对账
- 两条口径共存，不互相覆盖

## 验证方式

- 探针：`probes/v1-business-closure.evals.md`
- 入口 API：dashboard API / 汇总 SQL
- 评估：`evals/v1-business-closure.md`
- 对账：dashboard API 与 SQL 必须一致
