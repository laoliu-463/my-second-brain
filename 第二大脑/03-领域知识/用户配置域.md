# 用户配置域.md

> V1 用户域 + 配置域业务合同。详细：`D:\Projects\SAAS\docs\领域\用户域.md` + `docs/领域/配置域.md`。

## 用户域

### 职责

- 登录用户上下文
- 用户 / 角色 / 菜单
- 组织（4 部门：`department` / `recruiter_group` / `channel_group` / `ops_group`）
- `self / group / all` 数据范围
- 6 角色：管理员 / 渠道组长 / 渠道专员 / 招商组长 / 招商专员 / 普通成员

### 不负责

- ❌ 商品 / 订单 / 寄样 / 业绩的业务状态机
- ❌ 订单最终归属 / 提成 / 独家覆盖

### 规则

- 数据范围统一抽象为 `self / group / all`
- 业务域只消费用户域输出的数据范围，不复制权限规则
- 权限规则冲突先回到 `docs/07-权限与数据范围.md`

### 禁止越界

- 禁止用户域计算订单 / 寄样 / 商品 / 业绩归属
- 禁止业务域绕过用户域自行实现数据范围判断

## 配置域

### 职责

- 配置读取 / 保存 / 校验 / 版本 / 审计
- 系统配置、规则参数、提成比例、复制模板、`pick_extra`
- 对业务域提供配置查询能力

### 不负责

- ❌ 商品转链 / 订单归因 / 提成计算 / 寄样状态流转
- ❌ 直接触发业务动作
- ❌ 按 dataScope 过滤全局规则中心

### 规则

- 配置域只提供参数，**不执行具体业务规则**
- 规则执行由读取配置的业务域负责
- 配置变更必须保留：操作者、变更前后值、时间

### 禁止越界

- 禁止配置域计算业绩或归属
- 禁止配置域直接写商品 / 订单 / 寄样 / 业绩事实
- 禁止业务域直接改配置表绕过审计

## 验证方式

- 探针：`probes/rbac-scope.evals.md`（用户域）
- 入口 API：用户域 `users / roles / menus / data_scope`、配置域 `configs / config_audit`
- 评估：`evals/rbac-scope.md`
