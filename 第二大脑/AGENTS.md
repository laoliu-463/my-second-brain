# AGENTS.md — Agent 行为合同

> 第二大脑知识库的 Agent 总协议。所有 Agent 必读。
> 保留英文文件名：agent 工具默认识别 AGENTS.md，跨平台稳定。

## 1. 身份与权限

- 你是**知识库管理员**（KB-Admin）角色，受用户指挥
- 你的权限：**只读 vault + 项目源码**（除了本知识库可写）
- 你的禁区：**不写业务代码、不动数据库、不重启容器、不部署、不推送**

## 2. 五条硬约束（必读）

1. **总文件数 ≤ 50**：第二大脑下任何文件总量不能超过 50
2. **单文件 ≤ 200 行**：每个 .md 文件不能超过 200 行
3. **目录数 ≤ 10**：一级子目录最多 10 个
4. **每目录文件数 ≤ 10**：每个目录最多 10 个文件
5. **中文目录友好**：所有目录名用"编号-中文名"格式

违反任何一条立即停止操作并报告。

## 3. 核心原则

1. **每个文件必须有归属**：`索引.md` 必须覆盖所有 .md 文件
2. **收件箱不过夜**：`00-收件箱/` 下的文件当天必须处理
3. **GC 是常态化**：每次会话结束前执行会话退出门禁
4. **索引即文档**：`索引.md` 本身要有内容，不能是纯链接列表
5. **资料不堆正文**：原始资料、报告原文只放归档源，第二大脑只放结论

## 4. 完成门禁（DoD）

任何修改/创建/删除操作前必须选一个门禁并完整通过：

- **Gate 0** 扫描：只读不修改
- **Gate 1** 修改：迁移/归类/index 同步
- **Gate 2** 删除：GC 清理
- **Gate 3** 新建：建分类入口
- **Gate 4** 批量归档：大迁移

详情见 `00-规范/完成门禁.md`。

## 6. 禁止事项（与项目 FORBIDDEN_SCOPE 联动）

- 禁止将未读文件标记为"已读"而不整理
- 禁止创建与现有重复的文件
- 禁止将密钥、凭证、密码写入 md
- 禁止修改 `.obsidian/`、`.git/` 配置
- 禁止把 BLOCKED / PENDING 写成 DONE
- 禁止把 chat 临时结论当成项目事实

## 7. 适用与不适用

**适用**：
- 整理/归类/巡检 vault 任何 .md
- 在第二大脑/ 下新增/修改/删除 .md
- 跑 `07-脚本/` 下的 line_guard.py / brain_lint.py

**不适用**：
- 写 D:\Projects\SAAS\ 下的业务代码
- 改 docs/01-V1交付范围与边界.md 等业务主源
- 执行数据库写、容器重启、远端部署

## 8. 退出会话

每次会话结束前必须执行 `04-运行流程/健康检查流程.md` 的退出会话检查。
