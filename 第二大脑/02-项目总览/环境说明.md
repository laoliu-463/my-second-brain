# 环境说明.md

> V1 三种环境形态的边界、配置、操作入口。
> 详细：`D:\Projects\SAAS\docs\10-部署运行总览.md` + 团长 SaaS 知识库 `environment-部署环境/`。

## 1. 三种形态

| 形态 | 用途 | 后端端口 | 前端端口 | DB |
|---|---|---|---|---|
| local | 单机开发 | 8080 | 3000 | 本地 PG/Redis |
| test (mock) | Mock 回归基线 | 8080 | 3000 | 容器内 mock |
| real-pre | 真实上游预生产 | 8081 (127.0.0.1) | 3001 (127.0.0.1) | 容器内真实 PG/Redis |

## 2. 关键边界

| 维度 | test/mock | real-pre |
|---|---|---|
| 上游 | 假数据 | 真实抖音开放平台 |
| Token | 假 / mock | 真实应用 token |
| 端口绑定 | 0.0.0.0 | 127.0.0.1 强制 |
| 数据持久 | 不要求 | 必须 |
| 验收入口 | `npm run e2e:v1-p0` | `npm run e2e:real-pre:p0` |

## 3. 形态切换原则

- 任意时刻只能运行一种形态的 backend / frontend
- 容器重启必须先 down（不得 `-v`）
- real-pre 部署前必须 preflight

## 4. real-pre 必保开关

```text
APP_TEST_ENABLED=false
DOUYIN_TEST_ENABLED=false
DOUYIN_REAL_UPSTREAM_MODE=live
```

## 5. 远端服务器

- IP：1.14.108.159
- 项目目录：`/opt/saas/app/`（注意：不是 `/opt/saas/`）
- 容器：saas-active-backend-real-pre-1（8081）、saas-active-frontend-real-pre-1（3001）
- 部署入口：`deploy-remote.ps1 -Env real-pre -RemoteHost saas -RemoteDir /opt/saas/app`

## 6. 禁止事项

- 禁止 mock 化
- 禁止清库
- 禁止 `docker compose down -v`
- 禁止删除 PostgreSQL / Redis volume
- 禁止把 test 结果当成 real-pre 闭环

## 7. 健康检查

- 后端：`curl http://127.0.0.1:8081/api/system/health`（real-pre）
- 前端：`curl http://127.0.0.1:3001/healthz`（real-pre）
- test 前端：`/favicon.svg` 或 `/`
- 启动后等待 60-90 秒再检查（Spring Boot 初始化）
