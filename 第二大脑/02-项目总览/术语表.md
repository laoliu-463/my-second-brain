# 术语表.md

> V1 统一口径，避免 Agent / 文档混用。
> 业务事实主源：`D:\Projects\SAAS\docs\01-V1交付范围与边界.md`。

## 域与角色

| 术语 | 含义 |
|---|---|
| 团长 | 抖音联盟团长（V1 业务主角）|
| 渠道 | 团长角色之一，对应渠道组长 / 渠道专员 |
| 招商 | 团长角色之一，对应招商组长 / 招商专员 |
| 渠道主链 | 认领达人 → 商品库选品 → 转链 → 寄样 → 订单 → 业绩 |
| 招商主链 | 同步活动 → 活动商品入库 → 上架 → 审核寄样 → 订单 → 业绩 |
| 管理链 | 用户角色 → 数据范围 → 规则配置 → 权限生效 |

## 关键字段

| 字段 | 含义 | 域 |
|---|---|---|
| `pick_source` | 订单归因来源（系统转链/达人分享）| 订单域 |
| `colonel_buyin_id` | NATIVE 归因映射键 | 订单域 |
| `default_channel_id` | 订单默认渠道归属 | 订单域 |
| `default_recruiter_id` | 订单默认招商归属 | 订单域 |
| `pick_source_mapping` | 转链 → 订单归因映射 | 商品域 |
| `selected_to_library` | 活动商品入库商品库 | 商品域 |
| `audit_status` | 商品库审核状态 | 商品域 |
| `display_status` | 商品库展示状态 | 商品域 |
| `manual_disabled` | 商品库人工禁用 | 商品域 |
| `settle_amount` | 结算金额（双轨之一）| 业绩域 |
| `est_amount` | 预估金额（双轨之一）| 业绩域 |
| `performance_records` | 业绩记录表 | 业绩域 |
| `sample_requests` | 寄样申请表 | 寄样域 |

## 状态机

| 状态 | 含义 |
|---|---|
| `DONE` | 完成 + 证据齐 |
| `DONE_WITH_REGISTERED_DIRTY` | 完成但有已登记的脏工作区 |
| `PARTIAL_DIRTY_REMAINING` | 部分完成，有未提交变更 |
| `BLOCKED_BY_SAMPLE` | 缺真实样本 |
| `BLOCKED_BY_EXTERNAL` | 外部阻塞（权限/Token/上游）|
| `FAILED` | 失败 |
| `RISK_ACCEPTED` / `RISK_ACCEPTED_BY_USER` | 用户接受风险 |
| `PENDING` | 待处理 |
| `IN_PROGRESS` | 进行中 |
| `NOT_STARTED` | 未开始 |

## 环境

| 术语 | 含义 |
|---|---|
| `test` | mock / seed 回归基线 |
| `real-pre` | 真实上游预生产 |
| `APP_TEST_ENABLED` | 后端是否启用 test 模式 |
| `DOUYIN_TEST_ENABLED` | 抖音上游是否启用 test 模式 |
| `DOUYIN_REAL_UPSTREAM_MODE` | 抖音上游模式（`live` 为真实）|

## 决策缩写

| 缩写 | 含义 |
|---|---|
| ADR | Architecture Decision Record |
| V1 | 当前交付范围 |
| V2.2 | 旧完整方案（已归档）|
| E2E | End-to-End 端到端测试 |
| P0/P1/P2 | 优先级（阻塞 / 重要 / 次要）|
| DDD | Domain-Driven Design |
| MOCK | 假数据 / 假上游 |
