## 2. 关键调用关系

| 调用 | 路径 |
|---|---|
| 前端 → 后端 | `axios` 走 Gateway `/api/*` |
| 后端 → 抖音上游 | 开放平台 SDK + `DOUYIN_REAL_UPSTREAM_MODE=live` |
| 域间事件 | Spring 本地事件 + Outbox 机制（V1 简化，不强制 MQ）|
| 后端 → 缓存 | Redis 业务缓存 + 会话 |
| 后端 → DB | JPA / MyBatis，幂等键 + 同步日志 |

## 3. 模块边界（V1）

- **Controller**：薄入参出参，不编排业务规则
- **Application Service**：编排 use case，不持有跨域规则
- **Domain**：业务规则、不变量
- **Repository**：只做数据访问，不做业务
- **Adapter**：隔离外部接口（抖音 API、Redis 水位、Mapper）

## 4. 任务/事件流

- 订单同步 → 发布 `OrderSyncedEvent`
- `OrderSyncedEvent` → 寄样域消费（交作业）
- `OrderSyncedEvent` → 业绩域消费（最终归属）
- `OrderSyncedEvent` → 分析域消费（汇总）
- 退款 → 业绩域消费（冲正）

## 5. 外部依赖

- 抖音开放平台（订单、商品、达人）
- PostgreSQL / Redis
- Docker Compose（test / real-pre）
- 远端服务器 1.14.108.159（real-pre 部署）
