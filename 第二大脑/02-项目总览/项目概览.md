# 项目概览.md

> 抖音团长 SaaS（V1）项目背景。
> 完整版：`D:\Projects\SAAS\docs\00-项目总览.md` + 团长 SaaS 知识库 `01-project-overview.md`。

## 1. 项目名称

**抖音团长 SaaS**（V1）。面向抖音/抖店生态的团长（联盟）业务管理平台，承载渠道、招商、管理三类角色的核心业务操作。

## 2. 三条主链

| 主链 | 角色 | 入口合同 |
|---|---|---|
| 渠道链 | 渠道组长 / 渠道专员 | `docs/流程/渠道主链路.md` |
| 招商链 | 招商组长 / 招商专员 | `docs/流程/招商主链路.md` |
| 管理链 | 管理员 | `docs/流程/管理主链路.md` |

## 3. 八个领域

| 域 | 关键边界 |
|---|---|
| 用户域 | `self / group / all` 数据范围 |
| 配置域 | 配置不执行业务规则 |
| 商品域 | 负责转链与 `pick_source_mapping` |
| 达人域 | 维护达人资料与跟进 |
| 寄样域 | 通过订单已同步事件判断交作业完成 |
| 订单域 | 只存事实，不算提成 |
| 业绩域 | 最终归属、提成、冲正、双轨金额 |
| 分析模块 | 只读汇总表，不重算归属 |

## 4. V1 必不做（10 项）

1. 独家达人 / 商家覆盖
2. 经营毛利口径扩展（前端展示除外）
3. 个别品负责人覆盖
4. 商品负责人变更历史重算
5. 差异化提成
6. Cookie / 代理池
7. 物流 API 自动跟踪
8. 外部抖店快速寄样 `quick_sample_apply`
9. 数据平台整体导出
10. 不用 mock 数据证明真实闭环

## 5. 技术栈（V1）

| 层 | 选型 |
|---|---|
| 后端 | Spring Boot 3.2 / Java 17（模块化单体）|
| 持久化 | PostgreSQL |
| 缓存 | Redis |
| 编排 | Docker Compose（`test` / `real-pre`）|
| 前端 | Vue 3 / Vite / TypeScript / Pinia / Naive UI |
| 验证 | Playwright（E2E）/ Maven（Java 单测）/ Vitest（前端单测）|
| 外部依赖 | 抖音 / 抖店开放接口 |

## 6. 不变量

- V1 优先级 > 旧 V2.2 方案
- FastAPI / Celery 旧技术建议不适用
- 模块化单体，不拆微服务
- 订单域只存事实，不算提成
- 分析模块只读汇总，不重算业绩
- real-pre 不允许 mock
