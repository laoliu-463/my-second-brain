# README.md — 第二大脑

> 项目第二大脑（Second Brain）—— 把分散的文档、报告、状态、决策沉淀为可审计、可交接的可持续知识库。
> 保留英文文件名：GitHub / 编辑器默认识别。

## 1. 是什么

**第二大脑** 是本人在 WSL + Windows 双环境下的**个人/项目混合知识库**，按 Karpathy llm-wiki 思想组织：

- 每个文件必须有归属、有索引
- 结构清晰、来源可追溯、状态可交接
- 中文目录友好，文件中文为主
- 资料/报告不堆正文，只登记路径和结论

## 2. 服务对象

- **项目**：抖音团长 SaaS（V1）—— D:\Projects\SAAS\
- **个人**：地缘政治、大学物理、面试、认知成长、内容创作、后端知识体系
- **vault**：`/mnt/d/Docs/Books/my second brain/`

