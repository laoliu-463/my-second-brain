# 页面规范.md

> 每类页面的内容结构。每写一页前先看对应模板。
> 模板见 `08-模板/页面模板.md`。

## 1. 普通领域页（03-领域知识/*.md）

```text
# 领域名

## 领域职责（3-5 行）
## 领域不负责（3-5 行）
## V1 规则（5-10 行表格）
## 禁止越界（3-5 行）
## 验证方式（探针 + 脚本）
## 相关资料（链接）
```

## 2. 状态页（01-状态/当前状态.md 等）

```text
# 状态名

## 当前主线（3-5 行）
## 当前环境（表格）
## 当前高风险（3-5 行）
## 当前维护规则（3-5 行）
```

## 3. 项目总览页（02-项目总览/*.md）

```text
# 总览项

## 1. 目的 / 定位
## 2. 业务 / 技术维度（表格 + 链接）
## 3. 不变量 / 关键边界
## 4. 验证 / 入口命令
```

## 4. 流程页（04-运行流程/*.md）

```text
# 流程名

## 1. 触发条件
## 2. 步骤（编号）
## 3. 异常处理
## 4. 完成标志
```

## 5. 任务页（05-任务管理/任务-*.md）

```text
# 任务标题

## 任务 ID
## 状态：NEW / WIP / BLOCKED / DONE
## 触发
## 步骤
## 验证
## 证据
## 风险
```

## 6. 报告页（06-报告证据/报告-*.md）

```text
# 报告标题

## 1. 背景
## 2. 范围
## 3. 结论
## 4. 证据（路径）
## 5. 风险
## 6. 后续
```

## 7. 内容密度

| 类型 | 推荐行数 | 硬上限 |
|---|---:|---:|
| 状态页 | 30-80 | 200 |
| 领域页 | 50-100 | 200 |
| 总览页 | 30-80 | 200 |
| 流程页 | 30-60 | 200 |
| 任务页 | 20-50 | 200 |
| 报告页 | 30-100 | 200 |

## 8. 链接与引用

- 内部跳转：Obsidian wiki link 形式 `目录/文件.md`（外层方括号是模板占位符，复制时去掉）
- 外部路径：`/mnt/d/...` 或 `D:\...`
- 业务事实主源：`docs/01-V1交付范围与边界.md`
- 决策主源：`docs/决策/ADR-XXX.md`
- 项目 harness 主源：`D:\Projects\SAAS\harness\`
